# 引注核对表模板（GB/T 7714-2015）

供 `quality-gatekeeper` 在第 4 项闸门（引文真实性）使用。**本模板只给格式与核对口径，所有页码、版次、日期均须回原始出处核对后填写。**

---

## 一、适用对象

各时期领导人的著作、文选、讲话与文章，覆盖但不限于：毛泽东、邓小平、江泽民、胡锦涛、习近平。

按文献形态分四类，核对要点各不相同：

| 类型 | 标记 | 必须核对 | 高频错误 |
|---|---|---|---|
| 选集／文选／文集 | `[M]` | 卷次、**版次年份**、页码 | 缺版次；不同版次页码不同却混用 |
| 文集中的单篇 | `[M]//` | 所引文集名、卷次、版次、起止页 | 只写单篇名，漏掉文集出处 |
| 报纸上的讲话 | `[N]` | 报纸全名、**年-月-日**、版次 | 只写年份；版面写「第1版」而非 `(01)` |
| 官方网络发布 | `[EB/OL]` | 发布机构、发布日期、**引用日期**、可访问路径 | 缺引用日期；用了转载页而非官方页 |

---

## 二、著录格式模板

> `⟨⟩` 内为待核对项，禁止凭印象填写。

**1. 文集（整卷引用）**

```
毛泽东. 毛泽东选集: 第⟨卷次⟩卷[M]. 北京: 人民出版社, ⟨版次年份⟩: ⟨页码⟩.
```

**2. 文集中的单篇**

```
毛泽东. ⟨篇名⟩[M]//毛泽东选集: 第⟨卷次⟩卷. 北京: 人民出版社, ⟨版次年份⟩: ⟨起页-止页⟩.
```

**3. 报纸讲话**

```
⟨姓名⟩. ⟨讲话标题⟩[N]. 人民日报, ⟨YYYY-MM-DD⟩(⟨版次，两位数字⟩).
```

**4. 官方网络发布**

```
⟨姓名⟩. ⟨讲话标题⟩[EB/OL]. (⟨发布日期⟩)[⟨引用日期⟩]. ⟨官方发布页地址⟩.
```

> 版本控制铁律：同一篇文献在不同版次、不同印次中页码不同。正文引注与文末条目必须使用**同一个版次**，混用即判为缺陷。

## 三、核对表（逐条填写）

| # | 文中位置（页/段） | 引文类型 | 作者与文献名 | 卷次 | 版次/日期 | 页码 | 是否回原文核对 | 摘引是否完整 | 判定 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | 是／否 | 是／否 | |
| 2 | | | | | | | | | |
| 3 | | | | | | | | | |

**判定口径**

- `pass`：条目格式正确，页码可在声明版次中定位，摘引完整且不改变原意。
- `needs_revision`：格式缺陷（缺版次、缺版次日期、缺引用日期等），内容本身可核。
- `reject`：无法在原始出处定位；用二手转引冒充原文；摘引割裂原文、改变原意；文字与官方文本不一致。

---

## 四、六条硬规则

1. **只能引原始出处**。别人论文里转引的领导人讲话，不能当作来源。
2. **版本必须交代**。缺版次的文集引注一律判 `needs_revision`。
3. **摘引必须完整**。截断、拼接、改字以迁就论点，判 `reject`。
4. **文字须与官方文本逐字一致**。改写不是引用，若要改写须去掉引号并说明。
5. **报纸引注须有日期与版次**，缺一即缺陷。
6. **核不到就标「未核实」**。不得因为条目看起来规范就判合规。

---

## 五、交付物

核对完成后随验收报告提交：
- 本表（逐条填写完整）
- 缺陷清单（每条含：文中位置 → 问题类型 → 期望格式 → 责任成员）
- 结论：`pass` 仅当本表无 `needs_revision` 且无 `reject`
