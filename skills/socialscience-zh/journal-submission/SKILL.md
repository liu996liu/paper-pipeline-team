# 选刊与投稿实务

## 一、选刊：先排除，再排序

**不要先看影响因子。** 中文期刊的 IF 与其他指标口径混乱（知网复合影响因子 / 复合他引 /
万方影响因子各不相同），先按「能不能投」排除，再在剩下的里排序。

### 1.1 第一层：硬性排除（不符合就不必考虑）

| 检查项 | 怎么查 | 排除条件 |
|---|---|---|
| 是否在目标目录 | CSSCI 目录（南京大学，两年一版）/ 北大核心（《中文核心期刊要目总览》）/ CSCD / AMI | 单位考核要求的目录里没有 → 排除 |
| 是否收稿方向 | 看最近 6 期目录 | 近两年没发过你的主题 → 排除 |
| 是否接受自由投稿 | 看投稿须知 / 问同门 | 只发约稿、只发会议论文 → 排除（除非有推荐） |
| 是否收版面费 / 稿酬 | 投稿须知明示 | 超出预算 → 排除 |
| 审稿周期 | 投稿须知 / 中国知网「作者服务」/ 询问已发表作者 | 长于你的毕业或结项节点 → 排除 |
| 是否要求挂基金 | 看近期文章基金标注比例 | 几乎全挂国家级而你无基金 → 风险极高 |
| 作者身份门槛 | 看近期作者单位与职称分布 | 几乎全是双一流教授而你是在读硕士 → 风险极高（**这是中文期刊最现实的隐性门槛**） |

**关于作者身份门槛**：这一条必须在选刊时正面处理，不要等退稿才发现。可查的办法：
翻最近两年该刊目录，统计第一作者的单位层次与职称；若独立作者或硕士一作的比重
低于 5%，投中的概率就很低。此时应调整目标，或寻找可以带导师的期刊。

### 1.2 第二层：排序打分

对通过硬性排除的候选刊（通常 3–5 个）打表：

| 维度 | 权重 | 打分依据（1–5 分） |
|---|---|---|
| 主题契合度 | 35% | 近 6 期与你主题同领域的文章数（≥3 篇=5 分） |
| 目录等级 | 25% | 单位考核口径下的等级 |
| 审稿周期 | 20% | ≤2 月=5；3–4 月=4；5–6 月=3；>6 月=1 |
| 录用难度 | 10% | 结合作者身份门槛与近年发文量 |
| 格式负担 | 10% | 是否需要套模板、图表数量限制、字数限制 |

**主题契合度权重最高**，因为它最直接影响初审是否送外审。中文期刊初审退稿
（「不适合本刊」）绝大多数是契合度问题，不是质量问题。

### 1.3 常见选错

- **只看目录等级不看栏目**：投了一本 CSSCI，但该刊这个方向一年只发 2 篇 →
  初审几乎必退。正确做法是找**该方向是常设栏目**的刊。
- **同时投多家**：一稿多投是学术不端，见第四节。
- **忽视专刊/专题**：很多刊会出专题征稿，命中率远高于自由投稿。留意刊物公众号与投稿须知。

## 二、投稿前自检清单

### 2.1 摘要：GB/T 7713.2-2022 的要件

中文摘要**必须**包含四要素，缺一个就常被要求返修：

| 要素 | 写什么 | 长度占比 |
|---|---|---|
| **目的** | 研究要解决的问题 | 10–15% |
| **方法** | 数据来源、样本、分析方法（具体到模型/工具） | 20–25% |
| **结果** | 主要发现，**必须带具体数据**（系数、显著性、百分比） | 40–50% |
| **结论** | 理论或实践意涵（不是重复结果） | 15–20% |

**摘要五不要**：
1. 不要出现「本文」「我们」以外的第一人称复数（部分刊禁用第一人称，看须知）
2. 不要出现图表编号、参考文献序号、公式编号
3. 不要出现「具有重要的理论意义和现实意义」这类空话
4. 不要只写「研究发现 X 与 Y 显著相关」而不给方向与大小
5. 不要超过刊物字数上限（常见 200–300 字，部分刊 500 字）

**英文摘要**不要机翻。常见硬伤：
- 时态混乱（方法与结果用过去时，结论用现在时）
- `This paper` 与 `the paper` 混用
- 中文特有搭配直译（「紧密结合」→ `closely combine`，应为 `integrate`）
- 关键词与中文不对应

### 2.2 关键词

3–8 个（多数刊 3–5 个）。选取规则：
- 从**标题与摘要**里抽，不要另起炉灶；
- 用**学科规范词**（对照《汉语主题词表》或该刊已发文章的关键词）；
- 至少 1 个是**方法或理论**词，至少 1 个是**研究对象**词；
- 不要用「研究」「分析」「影响」这类无检索价值的泛词单列。

### 2.3 中图分类号与文献标识码

**中图分类号**（CLC）按《中国图书馆分类法》第五版：
- 一篇可给 1–3 个，主分类号在前；
- 社科常用：`F` 经济、`C` 社会科学总论、`G` 文化/教育、`D` 政治/法律、
  `B` 哲学、`H` 语言、`I` 文学、`K` 历史、`J` 艺术；
- 更细：`F272` 企业经济、`F323` 农业经济、`C912` 社会结构、`G647` 高等教育、
  `D630` 国家行政管理；
- **不确定就不要硬编**。查法：在知网按主题检索同类文章，看它们用哪个号，
  再回《中图法》确认层级含义。

**文献标识码**：
| 码 | 含义 |
|---|---|
| A | 理论与应用研究学术论文（**绝大多数原创论文用这个**） |
| B | 实用性技术成果报告 |
| C | 业务指导与技术管理性文章 |
| D | 一般动态性信息 |
| E | 文件、资料 |

### 2.4 基金项目与作者简介

**基金标注**：
- 格式：「基金项目：国家社会科学基金一般项目"XXX"（编号：20BGL012）」
- 只标与本文**确有支撑关系**的基金。堆三四个不相关的基金是常见减分项。
- 编号必须准确，编辑部会核。

**作者简介**（格式各刊不同，常见）：
```
作者简介：张三（1990— ），男，山东济南人，XX大学XX学院博士研究生，
主要从事组织行为学研究。
```
通讯作者单独标注（邮箱必给）。

### 2.5 参考文献格式

按 **GB/T 7714-2015**（多数刊仍用 2015 版；少数已声明用 2025 版，**以投稿须知为准**）。
两种制式：
- **顺序编码制**：正文用 `[1]` 上标，文后按引用顺序排列 —— 理工与多数社科刊
- **著者-出版年制**：正文用 `（张三，2020）`，文后按拼音/字母排序 —— 部分社科刊

**最常见退修原因（投稿前逐条核）**：
- [ ] 文献类型标识 `[J]/[M]/[D]/[C]/[N]/[EB/OL]` 缺失或错用
- [ ] 期刊缺「卷(期): 起止页」
- [ ] 专著缺出版地与出版者
- [ ] 学位论文误标为 `[J]`（应为 `[D]`）
- [ ] 报纸缺「年-月-日」与版次 `(01)`
- [ ] 电子文献缺发布日期与引用日期、URL
- [ ] 英文文献作者姓名格式错（GB/T 7714 要求姓全大写、名缩写，如 `SMITH J A`）
- [ ] 中文文献的英文译名缺失（部分刊要求中英对照参考文献表）
- [ ] 正文引用序号与文后列表不连续

**这三条可以用 `scripts/verify_paper.py citations` 自动查**，别手工核。

## 三、投稿信（Cover Letter）

### 3.1 中文期刊投稿信模板

多数中文刊不强制要求，但**附上会提高初审好感度**，尤其能解释「为什么投贵刊」。

```
尊敬的《XXXX》编辑部：

您好！

兹提交论文《XXXXXXXXXXXXXXXX》，申请在贵刊发表。

本文研究 [一句话问题]。采用 [数据/方法]，发现 [核心结论一句，带关键数据]。
与已有研究相比，本文的贡献在于：[贡献一]；[贡献二]。

本文选题与贵刊 [具体栏目名] 的定位相符，贵刊 20XX 年第 X 期刊发的
《XXXX》（作者）对本文有直接启发，本文在其基础上进一步 [差异点]。

本文未曾以任何形式公开发表，亦未同时投寄其他刊物。全体作者已阅读并同意
投稿，无利益冲突。基金支持：XXXXXXXX（编号：XXXX）。

恳请审阅，期待回复。

通讯作者：XXX
单位：XXXX
邮箱：XXX    电话：XXX
20XX 年 XX 月 XX 日
```

**关键**：第二段必须**具体到该刊的一篇文章**。泛泛写「贵刊在学界享有盛誉」等于没写。

### 3.2 英文 cover letter 要点

| 段落 | 内容 | 常见错误 |
|---|---|---|
| 1 | 投稿声明：题目、文章类型、期刊名 | 忘了写文章类型（Research Article / Review / Short Communication） |
| 2 | 研究问题与主要发现（2–3 句） | 写成摘要的复制粘贴 |
| 3 | 为什么适合这本刊（引用该刊近两年文章） | 只说「贵刊影响力大」 |
| 4 | 声明：未发表、未一稿多投、全体作者同意、无利益冲突 | 漏掉利益冲突声明 |
| 5 | 推荐/回避审稿人（如期刊要求） | 推荐了与自己同机构的合作者 |

**推荐审稿人的红线**：不得推荐近五年有共同发表、同机构、师生关系的学者。
被编辑发现会直接拒稿。

## 四、一稿多投、重复发表与撤稿

### 4.1 红线

| 行为 | 定性 | 后果 |
|---|---|---|
| 同一稿件同时投两家 | **一稿多投** | 两家都可能拒稿并列入黑名单；已发表则构成重复发表 |
| 同一研究拆成多篇（切香肠） | 可能构成**重复发表** | 需在文中明确引用前作并说明差异 |
| 已发表中文版再投英文版 | 需**双方编辑部知情同意** | 未声明即重复发表 |
| 会议论文扩展为期刊论文 | 通常允许 | 必须引用会议版并说明新增内容（一般要求 ≥50% 新内容） |
| 数据/代码未共享却声明共享 | 学术不端 | 撤稿 |

### 4.2 撤稿与改投

**投稿后想改投，必须先撤稿**：
1. 发邮件给编辑部，明确请求撤稿并说明原因（不要含糊）；
2. **等到编辑部书面确认**再投他处。只发邮件未获确认就改投，仍算一稿多投；
3. 保存撤稿确认邮件（后续可能被要求说明）。

**已被拒后改投**：正常流程，但必须按新刊要求重排格式，且**认真处理前一家审稿意见**。
把带旧刊格式、旧审稿意见批注的稿件投出去，是初审直接退的常见原因。

## 五、录用之后

| 环节 | 要做的事 | 易翻车点 |
|---|---|---|
| 校样（proof） | 逐字核对作者名、单位、基金号、图表、公式 | 只改错别字不核数据 → 见刊后无法改 |
| 版权协议 | 看清是转让还是授权、是否允许自存档 | 签了独占转让后不能自行上传预印本 |
| 版面费 | 确认金额、发票信息、付款节点 | 付款前确认是否含审稿费 |
| 网络首发 | 多数刊先网络首发再纸质 | 首发版可能就是最终版，**首发前必须核对完** |
| 见刊后 | 留存 PDF、更新 ORCID/个人主页、按单位要求登记 | 忘记登记影响考核认定 |

**校样阶段的三条铁律**：
1. 校样**只改错，不改内容**。大改会被要求重新审稿或直接拒。
2. 作者顺序与单位在录稿后基本锁定，改动需全体作者书面同意。
3. 数据、统计量、样本量逐一核对 —— **这是最后一次机会**。

## ❌ 你不做的事

- 不替用户决定投哪本刊（给决策矩阵和排除理由，选择权在作者）。
- 不编造期刊的影响因子、审稿周期、录用率 —— 查不到就写「需作者向编辑部确认」。
- 不代写 cover letter 里的作者声明（未发表、无利益冲突）—— 这些是作者的法定陈述，
  只能由作者确认后落笔。
- 不建议一稿多投、拆分发表、代写代投。

## 交付检查清单

- [ ] 候选刊 3–5 个，每个都有硬性排除的核查结论
- [ ] 选刊决策矩阵填完，权重与打分有依据
- [ ] 摘要四要素齐全，结果部分带具体数据
- [ ] 关键词 3–5 个，含方法/理论词与对象词
- [ ] 中图分类号已核对（不硬编）
- [ ] 文献标识码为 A（原创论文）
- [ ] 基金标注准确且与本文相关
- [ ] 参考文献已过 `verify_paper.py citations`
- [ ] cover letter 引用了该刊具体一篇近作
- [ ] 未发表/未一稿多投/全体作者同意/无利益冲突 四项声明齐备
