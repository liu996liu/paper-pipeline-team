# 中文期刊返修答复（修回说明）

## 零、先看三个数字

中国科协与多家人文社科期刊的编辑部统计里，**退修后最终录用的比例远高于初审直接录用**——
退修本身是好消息。但**返修稿被二次退修的最主要原因不是改得不够，而是答复不清楚**：
审稿人看不出你到底改了没有、改在哪、为什么这么改。

所以答复信的第一目标不是「辩解」，是**让审稿人在三分钟内核对完每一条意见**。

---

## 一、答复信的结构

```
一、总体说明（3–5 句）
   感谢 + 说明本轮修改的关键变化（不是逐条复述）+ 标注方式说明

二、逐条答复（按审稿意见的原始编号，一条不落）
   意见 X：[原文照抄，一字不改]
   答复：   [策略：接受/部分接受/不接受]
            [做了什么改动，改在哪一节哪一页哪一行]
            [为什么这么改（必要时给文献支撑）]
   修改处：第 X 页第 X 段（修订模式下标黄）

三、未采纳意见的说明（单独成节）
   每条给出：不采纳的理由 + 已采取的替代方案

四、其他修改
   未受审稿意见触发但主动改的（如发现的笔误、更新的数据），一并列出

五、结尾
   再次致谢 + 联系方式
```

**三条硬规矩**：
1. **意见原文照抄，不要改写**。改写会让审稿人以为你换了议题。
2. **一条不落**。漏一条，审稿人会认为你回避。实在做不到的，也要单独列出来说明。
3. **给坐标**。只说「已修改」等于没说。要写「第 7 页第 2 段」「表 3 注」「4.2 节末段」。

---

## 二、三种策略及判定

| 策略 | 什么时候用 | 表达方式 | 风险 |
|---|---|---|---|
| **接受并修改** | 意见成立，或虽不完全成立但改了能更好 | 「感谢指出，已按建议修改为……」 | 无 |
| **部分接受** | 意见的方向对，但具体做法不可行 | 「接受关于 X 的判断，已……；关于 Y，因数据限制无法……，改为……」 | 低（关键是要给替代方案） |
| **礼貌反驳** | 意见基于误解，或与事实/方法学冲突 | 见第四节论证结构 | **高**，必须一次到位 |

**判定顺序**：先问「我是不是真的错了」→ 再问「按他说的改会不会更差」→ 最后才问
「他是不是理解错了」。**跳过前两问直接反驳，是返修失败的头号原因。**

## 三、答复模板（可直接套用）

### 3.1 接受并修改

```
意见 3：作者在使用 DID 时未讨论处理组与对照组的平行趋势，建议补充检验。

答复：感谢审稿人的重要提醒。平行趋势是 DID 识别的关键前提，本文确实缺失该检验。
本轮已补充事件研究法（event study）的动态效应估计，以政策实施前 4 期为窗口，
结果显示各期系数均不显著（图 2），支持平行趋势假设。同时在 5.1 节补充了
安慰剂检验（随机分配处理组 500 次）作为佐证。

修改处：新增 5.1.2 节（第 12 页）、新增图 2（第 13 页）、新增表 A2（附录）。
```

### 3.2 部分接受

```
意见 5：建议将样本扩展到全国 31 个省份。

答复：接受审稿人关于样本代表性的关切。经核查，本文数据来源于 XX 数据库，
该库仅覆盖 2010 年后有连续统计的 26 个省份；其余 5 个省份在关键变量上缺失
超过 40%，纳入将引入不可忽略的测量误差。因此未扩展样本，改为：
（1）在 3.2 节明确说明样本范围与未纳入省份名单；
（2）在 6.3 节新增稳健性检验，按区域（东/中/西）分组回归，结果方向一致（表 A3）；
（3）在 7.2 节将「结论的适用范围限于 26 个省份」写入研究局限。
我们相信这一处理比强行纳入缺失数据更能保证结论可靠，也恳请审稿人指正。
```

### 3.3 礼貌反驳（高风险，慎用）

```
意见 7：中介效应应采用逐步回归法（Baron & Kenny, 1986）检验，作者仅报告
Bootstrap 区间，方法不够规范。

答复：感谢审稿人对中介效应检验方法的关注。我们理解逐步回归法在早期文献中的
广泛使用，但本轮未采用该方法，理由如下：

（1）方法学共识已更新。Zhao, Lynch & Chen (2010, Journal of Consumer Research)
    指出逐步回归法要求总效应显著，会漏掉总效应不显著但间接效应存在的遮掩效应；
    Hayes (2018) 与温忠麟、叶宝娟 (2014,《心理科学进展》) 均建议以 Bootstrap
    置信区间作为主要判据。本文遵循后者。

（2）本文数据存在遮掩效应。本文总效应为 0.08（p=0.21，不显著），而间接效应
    为 0.13（95% CI [0.05, 0.22]），若按逐步回归法将在第一步即终止，无法识别
    该机制。这一现象恰是本文的理论贡献之一（见 6.2 节）。

（3）为便于审稿人核对，已在表 4 注中同时报告逐步回归各步系数，并说明为何
    以 Bootstrap 结果为准。

我们尊重审稿人的判断，若编辑部认为需以逐步回归结果为主，我们可调整表述顺序。
```

**反驳的三条红线**：
1. **必须给文献**。没有文献支撑的反驳＝固执。
2. **必须给数据**。说「本文存在遮掩效应」就要给出实际系数。
3. **必须留台阶**。最后一句要表明愿意服从编辑部决定 —— 反驳的是方法，不是审稿人。

**绝对不能写的三句话**：
- 「审稿人显然没有认真阅读本文」——人身攻击，直接激化。
- 「这是学界公认的做法」——不给文献的空断言。
- 「由于时间/数据限制无法修改」——等于承认缺陷且不补救。

## 四、修改标注方法

| 方式 | 怎么做 | 适用 |
|---|---|---|
| **修订模式**（首选） | Word「审阅 → 修订」，所有改动留痕 | 绝大多数中文刊 |
| **痕迹版 + 清洁版** | 一份带修订痕迹，一份干净终稿 | 编辑部明确要求两份时 |
| **标黄 + 页边批注** | 改动处标黄，批注写「回应意见 X」 | 改版量大、修订模式混乱时 |
| **彩色区分轮次** | 第一轮红色、第二轮蓝色 | 二次返修 |

**必做的三件事**：
1. 文件命名写清轮次与版本：`稿件名_修回稿_R1_20251028.docx`、
   `稿件名_答复信_R1_20251028.docx`；
2. 答复信里的页码必须与**修回稿的实际页码**一致（改完格式后会变，最后再核一遍）；
3. 保留上一版，不要覆盖。

## 五、二次返修的特殊处理

二次返修时，审稿人通常只关心**上一轮的问题解决了没有**。答复信要变结构：

```
一、上一轮意见的落实情况（表格式，一行一条）
   | 意见 | 上轮答复 | 本轮状态 | 位置 |
   | 1 | 已补平行趋势检验 | ✅ 已完成 | 5.1.2, p12 |
   | 2 | 说明样本范围 | ✅ 已完成 | 3.2, p5 |
   | 3 | 扩展样本 | ⚠️ 部分完成 | 见下方说明 |

二、本轮新出现的意见逐条答复
三、本轮新增的修改
```

**「部分完成」必须单独解释**，不要混在「已完成」里蒙混。审稿人会核。

## 六、English response letter 对照（投英文刊时）

| 中文习惯 | 英文对应 | 注意 |
|---|---|---|
| 感谢审稿人的宝贵意见 | We thank the reviewer for this helpful comment. | 不要 `precious`/`valuable`，过于客套 |
| 已按建议修改 | We have revised accordingly (p. X, lines Y–Z). | 必须给行号 |
| 我们不同意 | We respectfully disagree. | 后面必须紧跟理由，不能单独成句 |
| 由于数据限制 | Due to data availability constraints, | 后面必须给替代方案 |
| 恳请审稿人指正 | We hope this addresses the reviewer's concern. | 不要说 `please correct me` |

**英文答复的格式要求**（多数刊强制）：
- 逐条编号，与 decision letter 编号一致；
- 每条分 `Reviewer comment:` / `Response:` / `Changes in manuscript:` 三段；
- 引用的修改处给**页码 + 行号**（不是节号）。

---

## ❌ 你不做的事

- 不替作者决定哪些意见可以不采纳（判断权在作者，你只给论证结构）。
- 不编造审稿意见原文。
- 不写「已修改」而不给具体位置。
- 不用「由于时间限制」作为不修改的理由。
- 不在答复信里与审稿人争论态度问题 —— 只谈学术。

## 交付检查清单

- [ ] 意见原文逐条照抄，编号与 decision letter 一致，一条不落
- [ ] 每条都有策略判定（接受/部分接受/反驳）与理由
- [ ] 每条都给了具体修改位置（页码/节号/图表号）
- [ ] 反驳的每一条都有文献支撑 + 数据支撑 + 台阶句
- [ ] 未采纳意见单独成节，有替代方案
- [ ] 主动修改（非审稿触发）单独列出
- [ ] 修订模式留痕，清洁版另存
- [ ] 答复信页码与修回稿实际页码核对一致
- [ ] 文件名标明轮次与日期，上一版保留
- [ ] 二次返修时，上一轮意见以表格列出落实情况
