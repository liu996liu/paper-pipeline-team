# 研究伦理与数据合规

## 零、为什么会需要这个

三件事让伦理与数据声明从「可选项」变成「必填项」：

1. **期刊要求**：越来越多 CSSCI 与医学人文类期刊在投稿系统里强制勾选「伦理审批号」
   与「知情同意」；没有，稿子进不了外审。
2. **基金结项**：国家社科/自科基金结项要求说明数据来源合规与数据共享安排。
3. **AIGC 声明**：2023 年后多数期刊明确要求披露生成式 AI 的使用范围与程度，
   未披露被发现，按学术不端处理。

**这一节的目标不是让你走完流程，是让你在正文与投稿材料里写出经得起核查的声明。**

---

## 一、伦理审查：什么时候需要，怎么做

### 1.1 判断表

| 研究类型 | 是否需要伦理审查 | 依据 |
|---|---|---|
| 涉及人类被试的问卷/访谈/实验 | **需要** | 人的研究，无论是否匿名 |
| 使用已公开的二手数据（统计年鉴、公开数据库） | 通常不需要 | 不涉及新的人的数据收集 |
| 使用机构内部数据（企业 HR 数据、医院病历） | **需要**（含数据使用许可） | 涉及隐私与机构授权 |
| 涉及未成年人、孕产妇、残障人士、服刑人员 | **需要 + 额外保护措施** | 弱势群体 |
| 涉及可识别的敏感信息（健康、性取向、政治倾向、收入明细） | **需要 + 加严去标识** | 敏感个人信息 |
| 纯文献/文本分析（公开出版物） | 通常不需要 | 但涉及版权与引用规范 |
| 网络爬取的用户生成内容 | **需要评估** | 平台条款 + 隐私预期 |

**经验判断**：只要「你能把某条数据对应到一个真实的人」，就需要审查。

### 1.2 审查材料清单

向本单位伦理委员会（或学术委员会）提交：

- [ ] 研究方案（含研究目的、对象、方法、样本量、时间安排）
- [ ] 知情同意书（模板见第二节）
- [ ] 调查问卷 / 访谈提纲全文
- [ ] 研究者资质与培训记录（部分单位要求）
- [ ] 数据管理计划（存储位置、保存期限、访问权限、销毁方式）
- [ ] 利益冲突声明

**审批周期**：常规 2–6 周，加急 1–2 周。**开题前就要启动**，不要等收完数据才补。

**批件编号写在哪**：正文「研究设计」或「数据来源」小节末，格式如
「本研究经 XX 大学伦理委员会审查批准（批件号：XXXX-2025-012），所有受访者均签署
知情同意书。」 **同时写进投稿系统的相应字段。**

## 二、知情同意书：必备要素

不是「我同意参加本研究」一句话就够。中文知情同意书必须包含以下 9 项：

| # | 要素 | 写法示例 |
|---|---|---|
| 1 | 研究目的 | 「本研究旨在了解……，不涉及任何商业用途。」 |
| 2 | 研究内容与时长 | 「您将完成一份约 15 分钟的问卷 / 一次约 60 分钟的访谈。」 |
| 3 | 自愿性 | 「参与完全自愿，您可随时退出，无需说明理由，且不会因此受到任何不利影响。」 |
| 4 | 风险与不适 | 「本研究不涉及身体风险；部分问题可能涉及工作压力等敏感话题，您可选择不回答。」 |
| 5 | 收益 | 「您不会获得直接经济报酬；研究结果可能为……提供参考。」（**不要许诺虚假收益**） |
| 6 | 隐私与保密 | 「数据将以编号代替姓名存储，仅研究团队可访问，发表时不会出现可识别您身份的信息。」 |
| 7 | 数据使用范围 | 「数据仅用于本项研究及后续学术发表，不用于商业目的，不向第三方提供。」 |
| 8 | 联系方式 | 研究者姓名、电话、邮箱；伦理委员会联系方式 |
| 9 | 签署 | 受访者签名 + 日期；研究者签名 + 日期；一式两份 |

**电子知情同意**（在线问卷）：首页展示上述 9 项，设置**必选**「我已阅读并同意」
才能进入下一页，并**记录同意时间戳**。事后无法举证「他同意了」，等于没同意。

**访谈录音的额外同意**：「本次访谈将录音以便准确整理，录音文件加密存储，
转录完成后 3 年内销毁。您是否同意录音？□ 同意 □ 不同意」
**不同意录音的受访者仍可参与**，改为现场笔记。

## 三、匿名化与去标识

### 3.1 三个层次（别混用词）

| 层次 | 做法 | 是否可复原 |
|---|---|---|
| **匿名化** (Anonymization) | 删除所有标识符，且**技术上不可复原** | 不可复原（严格意义） |
| **去标识化** (De-identification / Pseudonymization) | 用编号替代标识符，密钥单独保存 | **可复原**（有对照表） |
| **假名化** | 用化名（「张经理」「A 公司」） | 不可直接对应，但结合语境可能推断 |

**学术论文里做的事，99% 是去标识化或假名化，不是匿名化。** 写成「本研究已对数据
进行匿名化处理」而其实留着对照表，属于虚假陈述。**正确写法：「已进行去标识化处理，
编码与身份对照表由研究者单独加密保管，论文发表后销毁。」**

### 3.2 必须删的字段

| 数据类型 | 直接标识符 | 准标识符（组合可识别） |
|---|---|---|
| 问卷 | 姓名、学号、身份证号、手机号、邮箱、IP | 出生日期 + 性别 + 单位 + 职务 |
| 访谈 | 姓名、单位全称、具体职务 | 「某省某市某区某校初三年级组长」 |
| 企业数据 | 企业全称、统一社会信用代码 | 行业 + 地区 + 员工规模 + 成立年份 |

**准标识符是最容易出事的地方**。三个准标识符叠加，识别率可能超过 80%。
处理办法：**粗化**（出生日期→年龄段；单位全称→单位类型；具体职务→职务层级）。

### 3.3 引文处理的规矩

质性研究引用受访者原话时：
- 用编号 `A03` 而非姓名；
- 涉及具体地点、机构、人物的表述，用 `[某市]`、`[某企业]` 替代；
- **保留口语特征**（润色即失真），但删除可识别片段；
- 在方法部分声明化名规则。

**自查**：把一段引文给你的同事看，问他「你能猜到这是谁吗」。能猜到，就要再粗化。

## 四、数据保存、共享与 FAIR

### 4.1 保存期限（国内要求）

| 数据类型 | 最短保存期 | 依据 |
|---|---|---|
| 涉及人类被试的原始数据 | **研究结束后 ≥5 年**（部分单位 10 年） | 多数高校科研诚信管理办法 |
| 涉及临床/医学数据 | ≥10 年（部分 15 年） | 医学伦理规范 |
| 已发表论文的支撑数据 | ≥5 年，且期刊可能要求更久 | 期刊数据政策 |

**保存要求**：加密存储、访问留痕、异地备份、明确销毁流程。

### 4.2 数据共享声明（四选一，必须明确）

投稿时通常要在以下四类中声明一种：

| 声明类型 | 写法 | 适用 |
|---|---|---|
| **完全公开** | 「数据与代码已上传至 XX 平台（DOI: 10.XXXX/XXXXX），可公开获取。」 | 无隐私风险 |
| **受控访问** | 「因涉及受访者隐私，数据不公开，经合理请求并由伦理委员会批准后可获取。联系人：XXX。」 | 含敏感信息 |
| **部分公开** | 「问卷与代码已公开（DOI: …），原始数据因保密协议不公开。」 | 企业数据常用 |
| **不共享** | 「本研究数据不共享。」+ **必须给理由** | 最少见，容易被质疑 |

**只写「数据可向作者索取」** 是常见敷衍写法，越来越多期刊不接受。**改为「受控访问」
并写明审批路径。**

### 4.3 FAIR 原则的落地（不是背缩写）

| 原则 | 中文期刊场景的落地 |
|---|---|
| **F**indable 可发现 | 数据存到有 DOI 的仓储（Figshare/Zenodo/科学数据银行 ScienceDB） |
| **A**ccessible 可访问 | 给出稳定链接 + 访问条件，不要给个人网盘链接 |
| **I**nteroperable 可互操作 | CSV/TSV 而非 xlsx；变量名用英文短名 + 单独的 codebook |
| **R**eusable 可复用 | 必须有 codebook（每个变量的定义、编码、缺失值代码）+ 分析脚本 |

**最小可复用包**：`data.csv` + `codebook.md` + `analysis.py` + `README.md`（含复现步骤
与软件版本）。**只有数据没有 codebook，别人拿到也用不了。**

## 五、预注册

### 5.1 什么是预注册，为什么中文社科也需要

在做分析**之前**把研究假设、样本、变量、分析模型写死并存到公开平台，
用来区分「验证性研究」与「探索性研究」。

**中文社科的现实**：多数期刊不强制，但预注册能显著提升方法可信度，
尤其在被质疑「你是不是跑了很多模型挑显著的」时，预注册是唯一硬证据。

### 5.2 平台选择

| 平台 | 适用 | 备注 |
|---|---|---|
| **OSF** (osf.io) | 通用社科 | 最常用，支持注册后修订（带版本历史） |
| **AsPredicted** | 极简（9 个问题） | 适合快速登记 |
| **中国临床试验注册中心** (ChiCTR) | 医学/干预研究 | 国内强制 |
| **AEA RCT Registry** | 随机对照实验（经济学） | 有 DOI |

### 5.3 预注册要写什么（社科最小集）

```
1. 研究问题与假设（方向明确，不要写「探索 X 与 Y 的关系」）
2. 样本：目标量、抽样方法、功效分析依据
3. 变量：自变量、因变量、中介/调节、控制变量的测量方式
4. 分析模型：具体到方程与估计方法（OLS / logit / 多层线性 / SEM）
5. 排除标准：什么情况下剔除样本（作答时长、缺失率）
6. 探索性分析声明：哪些是事先没想好的
```

**关键**：预注册不是不能改。**改了要声明**：「原预注册采用 OLS，因因变量为计数
数据，实际改用负二项回归，此偏离已在结果部分说明。」**不声明才是问题。**

## 六、AIGC 使用声明

### 6.1 主流期刊政策的共同点

| 允许 | 不允许 |
|---|---|
| 用于语言润色、语法检查 | 列为作者 |
| 用于文献检索辅助（须人工核实） | 生成数据、结果、参考文献 |
| 用于代码编写辅助（须人工验证） | 生成整段论述而不加核实与改写 |
| 用于格式排版 | 替代研究设计与分析判断 |

**无论哪种使用，都必须声明。** 未声明而被检出，按学术不端处理。

### 6.2 声明模板

**中文（放在正文末「声明」或致谢前）**：

```
人工智能使用声明
本研究在写作过程中使用 [工具名与版本，如 DeepSeek-V4] 进行 [具体用途，
如 语言润色与英文摘要翻译]。作者对全文内容（包括所有数据、分析、
结论与参考文献）进行了独立核实，并对论文的完整性与准确性承担全部责任。
AI 工具未参与研究设计、数据分析与结果解释，亦未生成任何数据或参考文献。
```

**用途写得越具体越好**。「用于润色」比「用于辅助写作」可信；
「未生成任何数据或参考文献」这一句能打消审稿人最主要的疑虑。

**英文（投英文刊时）**：

```
Declaration of generative AI use
During the preparation of this work the author(s) used [tool] in order to
[improve language and readability]. After using this tool, the author(s)
reviewed and edited the content as needed and take(s) full responsibility
for the content of the publication.
```

### 6.3 三条红线

1. **不得用 AI 生成参考文献。** 幻觉文献是撤稿高发区，且极易被查。
2. **不得用 AI 生成或修饰数据。** 包括「让数据看起来更平滑」。
3. **不得用 AI 替代实质分析判断。** 模型选择、结果解释必须由作者负责。

## 七、作者署名与贡献

### 7.1 署名的四条标准（ICMJE，中文期刊普遍采用）

同时满足以下四条才可署名：
1. 对研究构思、数据获取或数据分析有**实质性贡献**；
2. 参与论文**起草或关键性修改**；
3. 对**最终版本**予以确认；
4. 同意对研究**整体负责**。

**只提供经费、只提供数据、只做语言润色、只是导师/领导，都不构成署名理由**
（可在致谢中体现）。

### 7.2 贡献声明格式（CRediT）

```
作者贡献声明
张三：研究构思、研究设计、数据分析、论文撰写；
李四：数据收集、数据清洗、论文修改；
王五：研究指导、论文审阅、经费支持。
```

**通讯作者**必须指定且承担联络与最终责任。**共同一作**需全体作者书面同意，
并在投稿时向编辑部说明。

### 7.3 署名争议的预防

- 开题时就**书面约定**作者顺序与贡献标准（邮件即可，留痕）；
- 投稿前全体作者**逐字确认**最终稿与署名顺序；
- 学生与导师之间最常见的争议是「导师是否够格署名」与「谁是一作」——
  **按上面四条标准逐条对照，而不是按资历。**
- 已投稿后变更署名：需全体作者签字的变更说明，编辑部可能要求说明理由并公示。

## ❌ 你不做的事

- 不替研究者签署任何声明（知情同意、利益冲突、AIGC 使用）—— 这些是研究者的法定陈述。
- 不虚构伦理批件号、预注册链接、数据 DOI。
- 不把「去标识化」写成「匿名化」。
- 不建议省略 AIGC 声明。
- 不替作者判断署名资格（只提供判定标准与争议处理路径）。

- [ ] 伦理审查是否需要已判定，需要的有批件号并写入正文
- [ ] 知情同意书九要素齐全，电子同意有必选项与时间戳
- [ ] 访谈录音有单独同意项
- [ ] 去标识化做法写清（不冒称匿名化）
- [ ] 准标识符已粗化，引文已处理可识别片段
- [ ] 数据保存期限与销毁安排明确
- [ ] 数据共享声明四选一，受控访问给了审批路径
- [ ] 可复用包含 data + codebook + script + README
- [ ] 如做了预注册：链接可访问；偏离已声明
- [ ] AIGC 使用声明具体到工具、版本、用途，并写明「未生成数据与文献」
- [ ] 作者贡献声明用 CRediT 格式，通讯作者明确
- [ ] 署名顺序经全体作者书面确认
