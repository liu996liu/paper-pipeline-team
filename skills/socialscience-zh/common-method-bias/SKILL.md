# 共同方法偏差（Common Method Bias）

## 一、为什么必须做

自评量表研究的致命威胁：**所有变量由同一个人在同一个时点、用同一种方式测量，
那么变量之间的相关可能不是真实关系，而是"答题习惯"造成的假象。**

典型表现：所有变量之间都显著正相关（r 在 0.3–0.6 之间整齐排列），
模型拟合异常好，什么假设都成立——这时候要怀疑共同方法偏差，而不是庆祝。

**中文核心期刊对自评数据几乎必问 CMV 检验。** 不做或只做 Harman，
会被审稿人认为方法学训练不足。

---

## 二、❌ 只做 Harman 单因素检验是不够的

### 2.1 做法

把所有题项一起做未旋转的探索性因子分析，看第一个因子解释的方差比例。

```
判据：第一个因子解释率 < 40% → 判定"不存在严重共同方法偏差"
```

### 2.2 为什么不够（必须知道，否则应答不了审稿人）

Harman 检验被广泛批评了二十多年（Podsakoff et al., 2003, 2012）：

1. **灵敏度极低**：它几乎检不出中等程度的 CMV。有模拟研究显示，
   当 CMV 真实存在且严重时，Harman 仍可能给出"通过"的结论。
2. **没有统计检验**：40% 这个阈值是经验约定，没有分布理论支撑。
3. **对题项数量敏感**：题越多，第一因子解释率越容易被摊薄。
4. **不能定位来源**：即使检出，也不知道是哪个变量被污染。

**所以：Harman 只能作为"例行公事"报一条，绝不能作为唯一证据。**
只报 Harman 的论文，方法部分的 CMV 论证是不完整的。

## 三、必须补做的三种检验（至少选一种）

### 3.1 CFA 标记变量法（marker variable）——推荐

**原理**：找一个理论上与其他变量都无关的变量（标记变量），
如果它与其他变量的相关显著不为 0，说明存在方法偏差。

**标记变量的选择标准：**
- 理论上与研究变量无因果关系；
- 但同样用自评方式测量（否则无法捕捉方法效应）；
- 常见选择：社会赞许性量表、情绪状态、一个无关的人格特质。

```r
library(lavaan)

# 基准模型：4 个研究变量 + 1 个标记变量，全部自由相关
model_baseline <- '
  F1 =~ Q1 + Q2 + Q3
  F2 =~ Q4 + Q5 + Q6
  F3 =~ Q7 + Q8 + Q9
  F4 =~ Q10 + Q11 + Q12
  FM =~ M1 + M2 + M3       # 标记变量
'
fit_b <- cfa(model_baseline, data = df)
summary(fit_b, fit.measures = TRUE, standardized = TRUE)

# 看标记变量与研究变量的相关
# 若所有相关都接近 0 且不显著 → 无明显 CMV
```

**判定**：标记变量与研究变量的相关系数绝对值均 <0.10 且不显著，
可论证"未发现明显共同方法偏差"。

### 3.2 不可测潜在方法因子法（ULMC）——最严谨

**原理**：在 CFA 模型里加一个"方法因子"，让所有题项都在它上面有载荷，
看加了方法因子后，原有路径系数是否大幅改变。

```r
# 基准模型（无方法因子）
model_base <- '
  F1 =~ Q1 + Q2 + Q3
  F2 =~ Q4 + Q5 + Q6
  F3 =~ Q7 + Q8 + Q9
'

# 加方法因子（所有题项都载荷在 FM 上，且 FM 与各因子不相关）
model_method <- '
  F1 =~ Q1 + Q2 + Q3
  F2 =~ Q4 + Q5 + Q6
  F3 =~ Q7 + Q8 + Q9
  FM =~ Q1 + Q2 + Q3 + Q4 + Q5 + Q6 + Q7 + Q8 + Q9
  FM ~~ 0*F1
  FM ~~ 0*F2
  FM ~~ 0*F3
'

fit_base   <- cfa(model_base,   data = df)
fit_method <- cfa(model_method, data = df)

# 比较：方法因子带来的方差比例
# 若方法因子载荷普遍很小、且拟合改善有限 → CMV 不严重
anova(fit_base, fit_method)
```

**判定标准**（Podsakoff 的做法）：比较加入方法因子前后，各路径系数的变化。
若变化幅度 <0.05（或 <10%），说明 CMV 不足以改变结论。

**注意**：ULMC 常出现收敛问题（模型识别不足），遇到时：
- 加约束（固定某些载荷相等）；
- 或退回到标记变量法；
- 在文中如实说明"ULMC 模型未能收敛，改用标记变量法"。

### 3.3 单因子模型对比（最简单，也最常被要求）

**原理**：把所有题项放在一个因子上，看拟合有多差。
如果单因子模型拟合也不差，说明所有题可能测的是同一个东西（严重 CMV）。

```r
model_single <- '
  F =~ Q1 + Q2 + Q3 + Q4 + Q5 + Q6 + Q7 + Q8 + Q9
'
fit_s <- cfa(model_single, data = df)
summary(fit_s, fit.measures = TRUE)

# 对比多因子模型
fit_multi <- cfa(model_base, data = df)
# 多因子模型应显著优于单因子模型
```

**判定**：多因子模型显著优于单因子模型（Δχ² 显著、ΔCFI >0.1、
单因子 RMSEA >0.10 而多因子 <0.08），可论证"不存在严重的共同方法偏差"。

## 四、程序性补救（研究设计阶段，比统计补救更有效）

**Podsakoff 反复强调：程序性补救优于统计性补救。** 统计补救是事后找补，
程序性补救是从源头切断。

| 措施 | 做法 | 效果 |
|---|---|---|
| **时间分离** | 前测测自变量，2–4 周后测因变量 | **最有效**，能切断瞬时状态与答题定势 |
| **来源分离** | 自评 + 他评（领导评下属、同伴互评） | 很有效，但组织难度大 |
| **方法分离** | 问卷 + 访谈 + 客观数据 | 有效 |
| **题项分离** | 把不同变量的题项打散，不按变量分块排列 | 中等有效，成本最低 |
| **匿名与保密** | 明确告知匿名、无对错 | 减少社会赞许性 |
| **反向题** | 部分题目反向表述 | 减少默认倾向（但会引入新问题，见下） |
| **量表改进** | 用成熟量表、题项表述清晰 | 减少测量误差 |

**反向题的双刃剑：** 反向题能抑制默认倾向，但会让α降低、因子结构变差
（尤其是低教育水平被试）。**用反向题就要在文中说明，且反向题不宜超过 1/3。**

**实践建议：** 如果研究设计阶段就能做时间分离（两次施测），
CMV 的论证会轻松很多，而且能让"因果"表述有底气。

## 五、中文期刊可接受的报告写法

### 5.1 完整版（推荐）

> **共同方法偏差检验**
>
> 由于本研究所有变量均由被试自我报告，可能存在共同方法偏差。为此，
> 本研究从程序与统计两方面进行控制。
>
> 程序方面，问卷采用匿名方式，明确告知被试答案无对错之分；
> 不同变量的题项交叉排列，避免被试猜测研究假设；部分题项采用反向表述。
>
> 统计方面，首先采用 Harman 单因素检验，将全部题项纳入未旋转的探索性
> 因子分析，结果显示第一个因子解释的变异量为 28.34%，小于 40% 的临界值。
> 其次，采用验证性因子分析比较单因子模型与四因子模型的拟合情况，
> 结果显示四因子模型（χ²/df=2.14，RMSEA=0.053，CFI=0.947，TLI=0.938，
> SRMR=0.046）显著优于单因子模型（χ²/df=8.76，RMSEA=0.138，CFI=0.412，
> TLI=0.356，SRMR=0.121；Δχ²=2143.52，Δdf=6，p<0.001）。
> 最后，引入社会赞许性量表作为标记变量，其与研究变量的相关系数
> 绝对值均在 0.08 以下且不显著。综合以上结果，本研究不存在严重的
> 共同方法偏差。

### 5.2 精简版（篇幅受限时）

> 采用 Harman 单因素检验，未旋转的第一个因子解释变异量为 28.34%，
> 低于 40% 的临界标准；验证性因子分析显示四因子模型拟合
> （χ²/df=2.14，RMSEA=0.053，CFI=0.947）显著优于单因子模型
> （χ²/df=8.76，RMSEA=0.138，CFI=0.412），表明共同方法偏差不构成严重威胁。

### 5.3 ❌ 不合格的写法

> ~~采用 Harman 单因素检验，第一个因子解释率为 35.2%，小于 40%，
> 说明不存在共同方法偏差。~~

**问题**：只有 Harman、没有其他证据、"说明不存在"过于绝对
（应说"未发现严重威胁"）。

## 七、常见错误清单

- [ ] 只做 Harman 检验，无其他证据
- [ ] 说"不存在共同方法偏差"（应为"未发现严重威胁"，绝对化表述不严谨）
- [ ] 标记变量选了与研究变量有理论关系的变量（如用"工作满意度"标记"组织承诺"研究）
- [ ] 单因子模型与多因子模型比较时，因子数不一致导致不可比
- [ ] ULMC 模型未约束方法因子与特质因子正交，导致结果无法解释
- [ ] 出问题后只在局限里写一句"可能存在共同方法偏差"，不做任何处理
- [ ] 程序性补救写了但实际没做（如声称"时间分离"，实际是一次性施测）

**最后一条是学术诚信问题。** 声称做了时间分离但实际没有，属于数据描述失实。
