# 样本量与统计检验力

## 一、为什么这件事在中文期刊越来越重要

十年前中文核心期刊基本不问样本量，现在越来越多的审稿人会问：

> 「作者未报告事前功效分析，无法判断样本量是否足以检验所提假设。」

**事前功效分析（a priori power analysis）** 已经成了方法部分的标配。
它回答一个问题：**在给定效应量和显著性水平下，我要多少人才有 80% 的把握
把真实存在的效应检出来？**

反过来，**样本量不足的后果是"假阴性"**：真实存在的效应，因为人太少没检出，
于是作者写"两者无显著差异"——这是错的，应该写"本样本量不足以检出该量级的效应"。

---

## 二、⚠️ 先避开三个最常见的误用

### 误用 1：用事后功效（post hoc power）为不显著的结果辩护

```
❌ "本研究不显著，但事后检验力为 0.78，接近 0.80，说明样本量基本充足。"
```

**这是统计上的循环论证。** 事后功效是 p 值的单调函数：p 不显著，
事后功效必然低；p 显著，事后功效必然高。它不提供任何新信息。

Hoenig & Heisey (2001) 直接称其为 "P-value fallacy"。
审稿人一旦看到 post hoc power，会认为作者不懂统计。

**正确做法**：
- 报告**观察到的效应量 + 95% CI**；
- 说明「CI 的上限意味着，即使存在效应，其量级也不会超过 X」；
- 或者做**敏感性分析**：在现有样本量下，能检出多大的最小可检测效应（minimum detectable effect, MDE）。

```
✅ "本研究 n=120，在 α=.05、power=.80 下可检出的最小效应量为 d=0.51。
   观察到的 d=0.28，其 95% CI 为 [-0.08, 0.64]，跨越 0，故不能排除小到中等
   的效应；本研究不足以支持"无效应"的结论。"
```

### 误用 2：用"经验法则"代替功效分析

```
❌ "根据 Nunnally 的建议，样本量应为题项数的 10 倍，故 30 题需要 300 人。"
```

10:1 是**因子分析的最低要求**，不是任何检验的功效依据。而且它太粗：
题项质量差时 10:1 远远不够，题项质量好时 5:1 也能收敛。

**经验法则可以作为下限声明，但不能替代功效分析。**

### 误用 3：效应量拍脑袋

```
❌ "取中等效应量 d=0.5"（无任何依据）
```

Cohen 的"小/中/大"是**他本人在社会心理学领域的观察总结，不是普适标准**。
在教育学、公共卫生、组织行为学里，"中效应"的含义完全不同。

**正确来源，按可信度排序：**
1. 本研究领域的**元分析**报告的合并效应量（最好）；
2. 同类研究的**前人结果**（次好，要说明来源）；
3. **预实验/预调查**的效应量；
4. 确实没有依据时，用 Cohen 惯例并**明确声明这是保守假设**，
   同时报告"若真实效应更小，所需样本量为 X"的敏感性分析。

## 三、各检验的样本量计算

### 3.1 两独立样本 t 检验

**公式（近似）：**

```
n per group = 2 × (z_{1-α/2} + z_{1-β})² / d²
```

α=.05（双尾）、power=.80 时，`(1.96 + 0.84)² ≈ 7.85`，所以：

```
n per group ≈ 15.7 / d²
```

| d | 每组 n | 总计 n |
|---|---|---|
| 0.2（小） | 394 | 788 |
| 0.5（中） | 64 | 128 |
| 0.8（大） | 26 | 52 |

**代码：**

```r
library(pwr)
pwr.t.test(d = 0.5, sig.level = 0.05, power = 0.80, type = "two.sample")
```

```python
from statsmodels.stats.power import TTestIndPower
analysis = TTestIndPower()
n = analysis.solve_power(effect_size=0.5, alpha=0.05, power=0.80,
                         ratio=1.0, alternative="two-sided")
print(f"每组需要 {n:.1f} 人")
```

**G*Power**：Test family = t tests，Statistical test = Means: Difference between
two independent means，填 Tail(s)=Two, Effect size d=0.5, α=.05, Power=.80。

### 3.2 单因素 ANOVA（k 组）

用效应量 f（不是 d）。换算：`f = d / 2`（两组时）。

| f | 判定 | k=3, n/组 | k=4, n/组 |
|---|---|---|---|
| 0.10 | 小 | 322 | 274 |
| 0.25 | 中 | 52 | 44 |
| 0.40 | 大 | 21 | 18 |

```r
pwr.anova.test(k = 3, f = 0.25, sig.level = 0.05, power = 0.80)
```

```python
from statsmodels.stats.power import FTestAnovaPower
FTestAnovaPower().solve_power(effect_size=0.25, alpha=0.05, power=0.80, k_groups=3)
```

### 3.3 回归（多元，检验 R² 增量或单个系数）

**检验单个系数的功效**（最常用）：

```r
library(pwr)
# f² = R²/(1-R²)；单个系数的 f² = 该系数的偏 R²/(1-总R²)
pwr.f2.test(u = 1, v = NULL, f2 = 0.15, sig.level = 0.05, power = 0.80)
# 返回 v = 分母自由度，n = v + u + 1
```

```python
from statsmodels.stats.power import FTestPower
# 或用 G*Power: Linear multiple regression: Fixed model, R² increase
```

**经验值**（α=.05, power=.80, 单个预测变量, f²=0.15 即中等效应）：**n ≈ 55**。
但：

- 每增加一个控制变量，需要额外样本；
- 一般建议 **n ≥ 50 + 8×预测变量数**（Green, 1991）；
- 逐步回归、交互项、调节效应需要更多。

### 3.4 相关分析

```r
pwr.r.test(r = 0.30, sig.level = 0.05, power = 0.80)
# r=0.30 需要 n=84
```

| r | 所需 n（α=.05, power=.80） |
|---|---|
| 0.10 | 783 |
| 0.20 | 194 |
| 0.30 | 84 |
| 0.40 | 47 |
| 0.50 | 29 |

**这条常被忽视：想检出 r=0.20 的相关，需要近 200 人。**
很多问卷研究 n=200 左右，却报了一堆 r=0.15 的显著相关——那是运气。

### 3.5 卡方检验

用效应量 w（Cramér's V 在小表时近似等于 w）。

| w | 小 | 中 | 大 |
|---|---|---|---|
| 2×2 | 0.10 | 0.30 | 0.50 |
| 3×3 | 0.07 | 0.21 | 0.35 |

```r
pwr.chisq.test(w = 0.30, df = 1, sig.level = 0.05, power = 0.80)
# 2×2 需 n=88
```

### 3.6 结构方程模型（SEM / PLS）

**SEM 没有简单的闭式公式**，用三条经验法则交叉验证：

| 法则 | 内容 | 来源 |
|---|---|---|
| **N:q 比** | 样本量 : 自由参数 ≥ 5:1，最好 10:1 | Jackson (2003) |
| **最小样本** | N ≥ 200（复杂模型 300+） | Kline (2016) |
| **RMSEA 精度** | 想达到 RMSEA 90% CI 宽度 .05，需 N≈400 | MacCallum et al. (1996) |

```r
library(semPower)
# 或用 Monte Carlo 模拟（推荐，最可靠）
library(simsem)
```

**PLS-SEM 的 10 倍法则已被证伪**（Hair et al., 2019 自己撤回了这条建议）。
改用 inverse square root method：

```
n_min = (2.486 / |β_min|)²      # power=.80, α=.05
```

若最小路径系数 β=0.20，则 n_min = 154。

### 3.7 多层线性模型（HLM）

**决定功效的不是总人数，而是组数。**

| 组数 | 结论 |
|---|---|
| < 30 | 组间方差成分估计不可靠，慎用 |
| 30–50 | 可接受的最低限 |
| > 50 | 推荐 |

Maas & Hox (2005)：组数 ≥ 50 时，组间方差与标准误的估计才基本无偏。
**每组人数影响不大，组数才是关键。** 这是"300 个学生分在 10 个班"的
研究最常见的致命伤——组数太少，ICC 估不准，标准误全错。

```r
library(simr)
model <- lmer(y ~ x + (1 | class), data = df)
powerSim(model, nsim = 100)
extend(model, along = "class", n = 60)   # 模拟加到 60 个班
```

## 四、问卷研究特有的样本量要求

### 4.1 题项与被试比例

| 比例 | 判定 | 适用 |
|---|---|---|
| < 5:1 | 不可接受 | — |
| 5:1–10:1 | 勉强可做 EFA | 题项质量高时 |
| 10:1–20:1 | 常规可接受 | 大多数期刊的默认期望 |
| > 20:1 | 稳健 | 复杂模型、要分样本时 |

**30 题的问卷，最小样本量应是 300。** 但更准确的说法是：

> 样本量的依据应是「要检验的效应量与模型复杂度」，
> 10:1 只是下限的经验提示。

### 4.2 EFA 与 CFA 分样本

**严格做法：一份数据做 EFA 探索结构，另一份数据做 CFA 验证结构。**
同一份数据既探索又验证，等于自己出题自己判卷，会被审稿人质疑。

```
总样本 600 → 随机分成两半（各 300）→ 一半 EFA，一半 CFA
```

做不到时，如实说明并承认这是局限（比装作没这回事好）。

### 4.3 问卷回收率与无效样本

**报告必须写清四组数字，缺一不可：**

```
发放 N1 = 800 份
回收 N2 = 683 份          → 回收率 85.4%
剔除无效 N3 = 47 份       → 剔除率 6.9%（含规律作答 21、缺失过半 18、反向题矛盾 8）
有效 N4 = 636 份          → 有效率 79.5%
```

**无效样本的剔除标准必须事前设定并在文中写明**，不能事后看着数据决定删谁。
常见可接受的标准：

- 作答时间 < 中位数 1/3（在线问卷）；
- 连续 10 题以上同一选项（直线作答）；
- 反向题与对应正向题答案矛盾；
- 关键变量缺失 > 20%（或用 FIML 处理，见下）。

### 4.4 缺失值处理

| 缺失比例 | 处理 |
|---|---|
| < 5% | 删除（listwise）可接受，但需报告 |
| 5%–20% | **FIML（全信息极大似然）或 MI（多重插补）**，不要简单删 |
| > 20% | 该变量考虑弃用，或做敏感性分析对比 |

**绝不能默认用均值填补后再当完整数据做检验**——这会人为缩小方差、放大显著性。
这是中文期刊非常常见的方法错误。

## 五、中文期刊可接受的报告写法

### 5.1 事前功效分析（推荐完整版）

> **样本量与统计检验力**
>
> 本研究采用 G*Power 3.1 进行事前功效分析。参照既有元研究的合并效应量
> （d≈0.35；作者，年份），设定 α=0.05（双尾）、power=0.80，
> 计算得两独立样本 t 检验所需总样本量为 262（每组 131）。
> 本研究最终获得有效样本 412 份，超过所需样本量，
> 统计检验力达到 0.94，满足分析要求。
>
> 对于结构方程模型部分，本研究模型含 28 个自由参数，
> 样本量与自由参数之比为 14.7:1，高于 10:1 的建议标准（Kline, 2016），
> 且 N=412 满足 RMSEA 置信区间估计的精度要求（MacCallum et al., 1996）。

### 5.2 敏感性分析（无先验效应量时，推荐）

> 由于本领域尚无同构念的元分析估计，本研究不做先验效应量假设，
> 改以敏感性分析报告最小可检测效应（MDE）。
> 在 N=412、α=0.05（双尾）、power=0.80 条件下，
> 两独立样本比较的最小可检测效应为 d=0.28，相关分析的最小可检测效应为 r=0.14。
> 本研究报告的效应量（d=0.31~0.52；r=0.19~0.41）均高于上述阈值。

**敏感性分析不需要假设效应量，因此更少被质疑，是"没有先验依据"时的最优解。**

### 5.3 ❌ 不合格写法

> ~~本研究共发放问卷 500 份，回收 450 份，有效问卷 430 份，
> 满足 Nunnally 建议的题项数 10 倍要求，样本量充足。~~

问题：回收率、剔除标准、剔除理由、每个检验的功效均未报告；
"样本量充足"没有依据。

### 5.4 报告框架（六项必填）

1. 目标样本量及**计算依据**（效应量来源、α、power、所用软件）
2. 实际发放、回收、剔除、有效的**四级数字与比率**
3. 剔除**标准**（事前设定）
4. 缺失值比例与**处理方法**
5. 与关键模型复杂度对照（N:q 比 / MDE）
6. 若样本量低于所需——**如实说明局限**，并给出 MDE

## 六、样本量不足时怎么办

**不要装作够。** 三条可接受的补救路径：

### 路径 A：改用对样本量更友好的方法

| 原计划 | 样本不足时改为 |
|---|---|
| SEM（需 N≥200） | PLS-SEM（inverse sqrt 法，N 可低至 100 左右） |
| 多组 SEM 比较 | 多组路径系数 bootstrap 比较 |
| 潜变量交互 | 显变量交互（牺牲测量误差校正） |
| 大样本 t 检验 | 贝叶斯因子（对小样本更稳健） |

### 路径 B：报告贝叶斯因子而非 p 值

小样本下 p 值极不稳定。贝叶斯因子能直接量化「数据支持 H1 相对于 H0 的程度」，
且不依赖抽样分布假设。

```r
library(BayesFactor)
bf <- ttestBF(x = g1, y = g2)
bf
# BF10 = 3.2 表示数据支持 H1 的程度是支持 H0 的 3.2 倍
```

| BF10 | 证据强度 |
|---|---|
| 1–3 | 微弱 |
| 3–10 | 中等 |
| 10–30 | 强 |
| > 30 | 极强 |
| < 1/3 | 支持 H0 |

**中文期刊接受度：逐年上升，但仍有审稿人不熟。建议作为补充而非替代。**

### 路径 C：如实降级结论

把「A 显著高于 B」改为「在本样本中 A 高于 B（d=0.31，95% CI [-0.02, 0.64]），
该差异未达统计显著；考虑到本研究的 MDE 为 d=0.51，不能排除小到中等效应的存在，
后续研究需更大样本检验」。

**这样写不会降低论文价值，反而显示方法自觉。** 掩盖样本量不足才降分。

## 七、常见错误清单

- [ ] 完全不做功效分析，被问到时无法应答
- [ ] 用事后功效（post hoc power）为不显著结果辩护
- [ ] 效应量取「中等」但不给任何来源
- [ ] 用 10:1 经验法则代替功效分析并声称"样本充足"
- [ ] 只报"有效问卷 430 份"，不报发放/回收/剔除
- [ ] 剔除标准事后确定、不写进方法
- [ ] 用均值填补缺失值后当完整数据做检验
- [ ] HLM 研究只报总样本量，不报组数
- [ ] PLS-SEM 用已废止的 10 倍法则论证
- [ ] EFA 与 CFA 用同一份数据却声称做了交叉验证
- [ ] 样本量不足时声称"达到统计要求"
- [ ] 把"p>0.05"写成"证明无差异"
