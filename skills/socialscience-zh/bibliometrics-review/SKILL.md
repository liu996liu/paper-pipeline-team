# 文献计量与系统性综述

## 零、先分清三种「综述」

审稿人最常毙的一点是：**方法不匹配**。三种综述的方法学完全不同，不能混用名字。

| 类型 | 回答什么 | 方法 | 可复现的关键 |
|---|---|---|---|
| **叙述性综述** (Narrative Review) | 某领域研究到了哪一步 | 专家判断 + 文献组织 | 选文标准与检索范围 |
| **系统性综述** (Systematic Review) | 某个具体问题的证据是什么 | PRISMA 流程 + 质量评价 | 检索式、筛选记录、双人编码 |
| **文献计量** (Bibliometric) | 知识结构长什么样 | 定量分析引文网络 | 数据库、检索式、软件参数 |

**「CiteSpace 跑出来的图 + 几段文字」不是系统性综述。** 如果只做知识图谱，
就老实叫「文献计量分析」，不要声称做了 PRISMA。

## 一、PRISMA 2020：系统性综述的四阶段

### 1.1 流程与计数

```
识别 (Identification)
  数据库检索 n = ____（CNKI + 万方 + WoS + Scopus，分别报）
  其他来源 n = ____（灰色文献、参考文献回溯）
        ↓
  去重后 n = ____
        ↓
筛选 (Screening)
  标题摘要筛选，排除 n = ____（原因分类计数）
        ↓
  全文获取 n = ____（获取失败 n = ____）
        ↓
纳入 (Included)
  全文评估，排除 n = ____（原因分类计数）
        ↓
  最终纳入 n = ____
```

**四个数字必须能对上**：`识别 - 去重 - 排除 = 最终纳入`。对不上就是错的。

**必须画 PRISMA 流程图**。不画，方法部分直接不完整。

### 1.2 排除原因要分类

不要写「排除 45 篇（不符合纳入标准）」。要写：

| 排除原因 | 篇数 |
|---|---|
| 非实证研究（评论、社论、书评） | 12 |
| 研究主题不符 | 18 |
| 无关键变量测量 | 8 |
| 重复发表 | 4 |
| 无法获取全文 | 3 |

**这个表是审稿人判断你是否真的筛过的核心证据。**

### 1.3 双人筛选与一致性

- 至少 20% 的文献由两人独立筛选；
- 不一致的由第三人裁定（**不是两人商量**，商量会趋同）；
- 报一致性：`Cohen's κ = 0.83`（筛选阶段常用 κ ≥ 0.70 或一致率 ≥ 90%）；
- 记录**裁定日志**：哪几篇有分歧、为什么。

### 1.4 纳入研究的质量评价

系统性综述必须评价纳入文献的质量，否则结论不可信。

| 研究类型 | 常用工具 | 评价维度 |
|---|---|---|
| 队列/病例对照 | **NOS**（Newcastle-Ottawa Scale，满分 9） | 选择、可比性、结果 |
| 横断面/描述性 | **CASP** 清单 或 **AHRQ** | 方法、样本、偏倚 |
| 混合方法 | **MMAT**（Mixed Methods Appraisal Tool） | 5 类研究各 5 题 |
| 随机对照 | **Cochrane RoB 2** | 5 个偏倚域 |
| 定性研究 | **CASP Qualitative** | 10 题 |

**中文期刊的现实**：社科领域纳入文献多为横断面问卷研究，用 **AHRQ 或 CASP** 最合适，
且要给出**逐篇评分表**（放附录），正文报分布（如「纳入的 32 篇中，高质量 11 篇、
中等 15 篇、低质量 6 篇」）。

## 二、检索式构造

### 2.1 CNKI 专业检索语法

知网「专业检索」支持字段代码 + 布尔逻辑：

| 字段码 | 含义 | 示例 |
|---|---|---|
| `SU` | 主题（标题+摘要+关键词） | `SU='数字化转型'` |
| `TI` | 篇名 | `TI='绿色创新'` |
| `KY` | 关键词 | `KY='低碳'` |
| `AB` | 摘要 | `AB='碳达峰'` |
| `FT` | 全文 | `FT='中介效应'` |
| `AU` | 作者 | `AU='张三'` |
| `AF` | 作者单位 | `AF='清华大学'` |
| `JN` | 期刊名称 | `JN='管理世界'` |
| `LY` | 文献来源 | `LY='CSSCI'` |
| `YE` | 年份 | `YE=2020` |

**示例（可直接改词使用）**：

```
SU=('数字化转型' + '数字技术' + '数字经济') AND SU=('绿色创新' + '绿色技术创新' + '环境创新')
AND LY='CSSCI' AND YE BETWEEN 2015 AND 2025
```

**注意**：
- `+` 是 OR，`*` 是 AND，`-` 是 NOT（不是 `AND`/`OR` 关键字，虽然部分版本兼容）；
- **同义词必须穷举**，这是检索式质量的核心。中国学者同一概念常有 3–5 种写法
  （「绿色创新」「绿色技术创新」「环境创新」「生态创新」）；
- 先跑一次宽检索看量级，再逐步收窄。**不要一开始就用窄检索式，会漏文献。**

### 2.2 英文库检索式

**WoS 核心合集**：
```
TS=(("digital transformation" OR "digitalization") AND ("green innovation" OR "environmental innovation"))
AND DT=(Article) AND PY=(2015-2025)
```

**Scopus**：
```
TITLE-ABS-KEY(("digital transformation" OR "digitalization") AND ("green innovation"))
AND DOCTYPE(ar) AND PUBYEAR > 2014
```

### 2.3 检索式必须完整报告

正文或附录给出**完整的、可粘贴复现的**检索式 + 数据库 + 检索日期 + 命中数。
**只说「以"数字化转型"和"绿色创新"为关键词检索知网，得到 312 篇」是不合格的** ——
别人无法复现你搜的是哪些同义词、限定了哪些来源。

## 三、文献计量分析

### 3.1 数据准备（决定成败的一步）

从 CNKI/WoS 导出后，**必做三件事**：

1. **作者名消歧**：同一人被写成「张三」「Zhang San」「Zhang S」→ 统一。
   CNKI 导出格式里中文作者已统一，但英文库混导出时必须处理。
2. **机构名合并**：「XX大学商学院」与「XX大学」→ 统一到学校层级（做机构分析时）。
3. **关键词合并**：把同义但字面不同的关键词合并（「绿色技术创新」与「绿色创新」），
   否则共现图会被切碎。**这一步要在 CiteSpace 用同义词表（alias list）做，
   不能手工改原始数据。**

### 3.2 三种分析的分工

| 分析 | 回答什么 | 软件 | 关键参数 |
|---|---|---|---|
| **关键词共现** | 主题聚集在哪些点 | VOSviewer / CiteSpace | 频次阈值、共现阈值 |
| **共被引分析** | 哪些文献是知识基础 | CiteSpace | 时间切片、g-index |
| **突现词检测** (Burst Detection) | 哪些主题在某个时期爆发 | CiteSpace | γ 参数（默认 1.0）、最短突现年数 |
| **文献耦合** | 哪些文献用了相似知识基础 | VOSviewer | 耦合阈值 |
| **合作网络** | 作者/机构/国家合作格局 | VOSviewer | 最大连线数 |

### 3.3 CiteSpace 参数（必须报告）

| 参数 | 典型值 | 说明 |
|---|---|---|
| Time Slicing | 2015–2025，slices = 1 | 按年切 |
| Node Type | Keyword / Cited Journal / Author 等 | 一次只选一种 |
| Selection Criteria | **g-index k=25** 或 Top N=50 | 两种不能混用同一图 |
| Pruning | **Pathfinder** + **Pruning sliced networks** | 不剪枝图会成毛线团 |
| 突现检测 | γ=1.0，Minimum Duration=2 | γ 越小突现词越多 |

**必须报告：Q 值（模块度）与 S 值（平均轮廓值）。**
- `Q > 0.3` 表示网络结构显著；
- `S > 0.7` 表示聚类结果令人信服（0.5–0.7 之间是「合理」，需说明）；
- 这两个数字不放，审稿人会问「你的聚类可靠吗」。

### 3.4 VOSviewer 参数

- 阈值选择：最小出现次数（如 ≥5），最小共现次数；
- 聚类分辨率（resolution）默认 1.0，调大分得更细；
- 最小聚类规模（min cluster size）；
- **必须报告：节点数、连线数、总连接强度、聚类数与各聚类规模。**

### 3.5 bibliometrix（R）—— 做三线表最方便

```r
library(bibliometrix)
# 读知网 CNKI 导出（需先转成 bib 或 scopus 格式）
M <- convert2df("export.txt", dbsource = "wos", format = "plaintext")

# 描述性统计（直接可入表 1）
results <- biblioAnalysis(M)
summary(results, k = 20)

# 年度发文趋势
library(ggplot2)
ggplot(results$AnnualProduction, aes(x = Year, y = Articles)) +
  geom_line(color = "#2c7fb8", linewidth = 0.9) +
  geom_point(size = 2) +
  labs(x = "年份", y = "发文量") +
  theme_classic(base_size = 12)

# 关键词共现与主题图
NetMatrix <- biblioNetwork(M, analysis = "co-occurrences", network = "keywords", sep = ";")
net <- networkPlot(NetMatrix, n = 50, Title = "关键词共现", type = "fruchterman",
                   labelsize = 0.8, halo = TRUE)

# 三线图（战略坐标：中心度 vs 密度）
themeResults <- thematicMap(M, field = "ID", n = 250, minfreq = 5)
```

## 四、发表偏倚

系统性综述若含定量合成（meta 分析），**必须**评估发表偏倚，只做叙述性综合的可说明为何不做。

| 方法 | 适用条件 | 怎么读 |
|---|---|---|
| **漏斗图** (Funnel Plot) | 纳入研究 ≥10 篇 | 不对称 → 可能有偏倚（但不对称也可能源于异质性） |
| **Egger's test** | 纳入研究 ≥10 篇 | `p < 0.10` 提示不对称（注意：不是 0.05） |
| **Begg's test** | 同上 | 检验力低，仅作补充 |
| **Trim and fill** | 有偏倚时 | 估计需补多少篇、校正后效应量 |
| **失安全系数** (Nfs) | 补充 | 需多少未发表研究才能推翻结论 |

**中文 meta 分析的常见错误**：
- 纳入 5 篇还画漏斗图（检验力不足，图不可读）；
- 用 `p < 0.05` 判 Egger（应为 0.10）；
- 只报漏斗图不报检验统计量；
- 异质性 `I² > 75%` 还硬做固定效应模型。

**异质性处理**：
| I² | 含义 | 模型选择 |
|---|---|---|
| <25% | 低 | 固定效应可接受 |
| 25–50% | 中 | 随机效应 |
| 50–75% | 较高 | 随机效应 + 亚组分析 |
| >75% | 高 | **不宜合并**，改做叙述性综合或亚组分析 |

## 五、结果怎么写进正文

### 5.1 文献计量的正文骨架

```
3 数据与方法
  3.1 数据来源与检索策略（检索式全文 + 日期 + 命中数）
  3.2 筛选标准与流程（PRISMA 图或纳入排除表）
  3.3 分析工具与参数（CiteSpace 版本、参数逐项列出）

4 结果
  4.1 发文趋势（图 1：年度发文量；文字给三个阶段的年均值）
  4.2 期刊与机构分布（表 1：Top10 期刊，含载文量与影响因子）
  4.3 作者与合作网络（图 2；说明核心作者群是否形成 —— 用普赖斯定律）
  4.4 关键词共现与聚类（图 3；表 2：聚类编号/标签/轮廓值/主要关键词）
  4.5 突现词与阶段演化（图 4；按阶段描述主题迁移）
  4.6 共被引的知识基础（图 5；指出奠基性文献）

5 讨论
  5.1 研究热点归纳（把聚类翻译成人话，不要只报软件输出）
  5.2 演进脉络（突现词 → 阶段划分 → 为什么这个阶段转向）
  5.3 研究空白与本文定位
```

### 5.2 三条最容易犯的错

1. **只报图不解释**：「如图 3 所示，共得到 8 个聚类」。 → 必须解释每个聚类
   是什么主题、由哪些文献支撑、彼此什么关系。
2. **把软件默认标签当结论**：CiteSpace 的聚类标签常是无意义的词。
   **必须人工重新命名聚类**，并说明命名依据（代表文献的标题/摘要）。
3. **普赖斯定律用错**：核心作者判定公式是 `m = 0.749 × sqrt(n_max)`，
   其中 `n_max` 是最高产作者的发文量，发文量 ≥ m 的作者为核心作者。
   算完要报核心作者人数与占比，再判断「核心作者群是否形成」。

## ❌ 你不做的事

- 不把「跑了 CiteSpace」当成做了系统性综述。
- 不编造检索命中数、PRISMA 计数、Q/S 值、κ 值。
- 不为了图好看而隐藏低质量聚类或调参到满意为止（**调参必须报告，且只能调一次**）。
- 不用中文库的导出数据直接在英文软件里跑而不做作者名与机构名消歧。

## 交付检查清单

- [ ] 综述类型声明唯一（叙述性/系统性/文献计量），方法与名称匹配
- [ ] 检索式完整可复现（字段码、同义词、布尔逻辑、日期、命中数）
- [ ] PRISMA 四阶段计数能对上，排除原因分类计数
- [ ] 双人筛选比例与一致性系数
- [ ] 纳入研究质量评价工具与逐篇评分
- [ ] 数据预处理三步（作者消歧/机构合并/关键词合并）已做并报告
- [ ] 软件版本与全部参数报告（含 CiteSpace 的 Q 值与 S 值）
- [ ] 聚类已人工命名，命名依据说明
- [ ] 图不是只摆着，每张图都有解释段
- [ ] 发表偏倚（如做 meta）用对阈值与模型
