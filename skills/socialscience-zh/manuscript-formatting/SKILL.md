# 交稿排版（Markdown → 中文期刊 Word）

## 零、为什么不能直接 Markdown 交稿

中文核心期刊**九成以上只收 Word**，且格式审查是初审的第一道关。常见致命项：

| 项 | 要求 | Markdown 默认做不到 |
|---|---|---|
| 中文字体 | 正文宋体小四（12pt），标题黑体 | 无字体概念 |
| 行距 | 1.5 倍 或 固定值 20 磅 | 无 |
| 首行缩进 | 2 字符 | 无 |
| **三线表** | 顶线、表头线、底线，无竖线 | `|` 表格带竖线 |
| 图表题注 | 图 1 xxx（图下）／表 1 xxx（表上） | 无 |
| 页码 | 页脚居中，从正文起编 | 无 |
| 脚注引注 | 上标数字 + 页下注（部分刊） | 无 |
| 公式 | Word 原生公式（OMML） | LaTeX 源码 |
| 参考文献 | 悬挂缩进、顺序编码 | 列表 |

**所以必须有一步真正的转换。** 两条路线：

| 路线 | 工具 | 适用 | 代价 |
|---|---|---|---|
| **A. 模板套用**（推荐） | `pandoc --reference-doc=模板.docx` | 期刊提供了 Word 模板 | 需手工补三线表、题注 |
| **B. 脚本生成** | `python-docx` + 样式表 | 期刊无模板，或需严格控制 | 要写代码，但一次写好复用 |

本技能给 B 路线一个可直接用的脚本，A 路线给命令。

---

## 一、路线 A：pandoc + 期刊模板

```bash
# 1) 从期刊官网下载投稿模板 template.docx
# 2) 用模板的样式渲染（模板里的"标题 1/正文/图表题注"样式会被沿用）
pandoc manuscript.md \
  -o submission.docx \
  --reference-doc=template.docx \
  --from markdown+pipe_tables+footnotes \
  --citeproc --bibliography=refs.bib --csl=china-national-standard-gb-t-7714-2015-numeric.csl
```

**GB/T 7714-2015 的 CSL 文件**（直接用，无需自造）：

```bash
curl -LO https://raw.githubusercontent.com/citation-style-language/styles/master/china-national-standard-gb-t-7714-2015-numeric.csl
# 著者-出版年制用：
curl -LO https://raw.githubusercontent.com/citation-style-language/styles/master/china-national-standard-gb-t-7714-2015-author-date.csl
```

> 注意：这是 **GB/T 7714-2015**。少数期刊已声明改用 2025 修订版，**以投稿须知为准**。
> 若期刊要求**脚注制**（页下注），那是 **CY/T 121-2015**，不是 GB/T 7714 —— GitHub 上
> 没有成熟的现成 CSL，需用路线 B 手工生成脚注。

**pandoc 路线的三个必补**（pandoc 做不到，转换后手工补）：
1. **三线表**：pandoc 输出的表格带竖线边框。选中表格 → 设计 → 边框 → 无框线，
   再单独加顶线、表头下线、底线（1.5 磅 / 0.75 磅 / 1.5 磅）。
2. **图表题注**：pandoc 会把 `![图 1 xxx](a.png)` 变成带题注的图，但题注位置与
   字体需按刊要求改。表题注要在表**上方**，pandoc 默认在上方，检查即可。
3. **页码与页眉**：模板里通常已有；若无，插入 → 页码 → 页面底端 → 居中，
   并设置「首页不同」与「从正文开始编号」。

## 二、路线 B：脚本生成（推荐，可复用）

仓库自带 `scripts/docx_build_submission.py`，纯 python-docx，无需 pandoc。

```bash
python scripts/docx_build_submission.py manuscript.md \
  --out submission.docx \
  --template journal.docx \        # 可选：套用期刊模板的样式
  --title "题名" --author "张三" --affil "XX大学XX学院" \
  --abstract abstract.md --keywords "数字化转型;绿色创新;中介效应" \
  --clc F272 --doccode A \
  --fund "国家社会科学基金一般项目（20BGL012）" \
  --refs refs.md
```

它会做：

| 部分 | 处理 |
|---|---|
| 题名页 | 中文题名（黑体二号居中）、作者、单位、摘要、关键词、中图分类号、文献标识码 |
| 英文部分 | Title / Author / Affiliation / Abstract / Keywords（可选） |
| 正文 | 宋体小四、1.5 倍行距、首行缩进 2 字符；标题黑体分级 |
| 表格 | Markdown 管道表 → Word 真表格，自动套**三线表**（仅上下框线 + 表头下线） |
| 图 | 图片居中插入，题注在图下，宋体五号 |
| 脚注 | `[^1]` 语法 → Word 真脚注（页下注），上标编号 |
| 公式 | `$...$` 保留为文本并在稿末列出待转清单（OMML 需 Word 内手工或用 MathType 批量转） |
| 页码 | 页脚居中域，从正文页起编 |
| 参考文献 | 悬挂缩进，按 GB/T 7714-2015 校验必备要素 |

**注意**：脚本不替你判断格式对不对 —— 它只把「能自动化的」做掉。
**最后必须人工过一遍投稿须知**（字号、页边距、图表数上限、字数上限）。

## 三、三线表的正确做法

三线表不是「看起来像三线」，是**只有三条横线**：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━   1.5 磅（顶线）
 变量    M      SD      α
━━━━━━━━━━━━━━━━━━━━━━━━━━   0.75 磅（表头下线）
 X1    3.42   0.87   0.82
 X2    2.91   0.94   0.79
━━━━━━━━━━━━━━━━━━━━━━━━━━   1.5 磅（底线）
```

**Word 里怎么设**：
1. 选中表格 → 「表格设计」→「边框」→「无框线」；
2. 保持选中 → 「边框和底纹」→ 自定义；
3. 顶线：宽度 1.5 磅，点「上框线」；
4. 表头下线：宽度 0.75 磅，选中表头行，点「下框线」；
5. 底线：宽度 1.5 磅，点「下框线」（整个表格）。

**表注**：放在表格**下方**（与表题分开），说明数据来源、显著性标记含义、样本量。
```
注：N = 412。*** p < 0.01，** p < 0.05，* p < 0.1。括号内为稳健标准误。
数据来源：作者根据 XX 数据库整理。
```
**千万不要把表注和表题混在一起放表格上方。**

## 四、图的要求

| 项 | 要求 |
|---|---|
| 分辨率 | ≥300 dpi（线条图 ≥600 dpi，灰度照片 ≥300 dpi） |
| 格式 | TIFF / EPS / 高质量 PNG；**不要用截图** |
| 字号 | 图中文字不小于 7 pt，与正文字体协调 |
| 色彩 | 保证黑白打印可辨（用线型/标记区分，不只靠颜色） |
| 题注 | 图**下方**，「图 1 xxx」，与正文引用一致 |
| 数量 | 多数刊限制 6–8 幅，超出需说明必要性 |
| 单独文件 | 部分刊要求图片另存为单独文件并命名（fig1.tif） |

**中文图最常见的退修原因**：图内文字是英文但正文是中文（未统一）；坐标轴缺单位；
图例遮挡数据；从 Excel 直接截图粘贴（分辨率不足）。

## 五、公式

**要有编号的公式**必须用 Word 原生公式（OMML），不能是图片或纯文本。

| 做法 | 说明 |
|---|---|
| Word 内置公式编辑器 | `Alt + =`，手打或用 LaTeX 输入模式 |
| MathType | 期刊若要求，按其规范 |
| pandoc `--to docx` | LaTeX 公式自动转 OMML（**这是 pandoc 路线的一大优势**） |
| 纯文本 | ❌ 不接受 |

**公式编号**：右对齐加圆括号 `(1)`，与正文引用 `式(1)` 一致。
多行公式用 `\begin{aligned}`；编号在每行或整组末尾，按刊要求。

## 六、脚注引注（CY/T 121-2015）

部分人文社科刊（历史、法学、文学）要求**页下注**而非文后参考文献表。规则：

| 文献类型 | 首次引用格式 |
|---|---|
| 专著 | 作者：《书名》，出版地：出版社，年份，第 X 页。 |
| 期刊论文 | 作者：《篇名》，《刊名》XXXX 年第 X 期，第 X 页。 |
| 学位论文 | 作者：《题名》，XX 大学博士学位论文，年份，第 X 页。 |
| 报纸 | 作者：《篇名》，《报纸名》XXXX 年 X 月 X 日第 X 版。 |
| 古籍 | 作者：《书名》，版本，卷次，页码。 |
| 网络资源 | 作者：《篇名》，网址，访问日期。 |

**重复引用**：`同上书，第 X 页。` / `同前注〔X〕，第 X 页。`
**英文文献**首次全引，重复用 `Ibid.` 或 `Op. cit.`。

**与 GB/T 7714 的区别必须在开题时就确认**：投历史/法学/文学刊基本是脚注制，
投经济/管理/教育刊基本是文后表。**搞错等于重排。**

## 七、交稿前的机械核对（用脚本，不要肉眼）

```bash
# 统计量与正文数字一致性
python scripts/verify_paper.py numbers manuscript.md --results 30-analysis/results

# 参考文献 GB/T 7714-2015 必备元素
python scripts/verify_paper.py citations manuscript.md

# 参考文献条目数 vs 正文引用最大序号
python scripts/verify_paper.py citations manuscript.md --check-numbering
```

这三条过不了的稿子，投出去也会在格式审查阶段被打回。

## ❌ 你不做的事

- 不做「看起来像三线表」的假三线（带竖线、边框不统一）。
- 不把公式转成图片。
- 不擅自改期刊要求的字号、页边距、字数。**以投稿须知为准，不确定就留原样并标注。**
- 不用 Excel 截图当图。
- 不在转换后不核对就宣称「已排版完成」。
