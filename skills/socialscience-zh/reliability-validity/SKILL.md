# 信度与效度分析

## 先决条件：分析前的三件准备工作

这三件没做完就报信效度，数字全部作废。

**一、反向题先反向。** 量表里凡有"我不认为……""我很少……"这类反向表述题，必须先
`score = (max + min) - raw` 转换。漏转一题，该维度 α 会掉到 0.3 以下，而你会以为是
题目质量差，实际是计分错。检查办法：跑一次 `item-total correlation`，出现大面积负值
几乎必然是反向题没转。

**二、缺失值先处理并写明。**

| 缺失比例 | 处置 | 必须在正文写什么 |
|---|---|---|
| <5% | 删除该样本，或均值/中位数填补 | 填补方法与缺失机制判断 |
| 5%–20% | FIML / 多重插补，或删除该题 | 为什么删题而不是删人 |
| >20% | 该题作废 | 作废依据，不要硬撑 |

整份问卷缺失超过 20% 的样本直接剔除，剔除标准写进 `data-dictionary.md`。

**三、样本量先看够不够。** 信效度分析对样本量的最低要求：
- 做 α：题数的 5–10 倍，且 N≥100；
- 做 EFA：题数的 5–10 倍，且 N≥150（更严格的做法是 N≥200）；
- 做 CFA：每个待估参数 5–10 个样本，通常 N≥200；
- 做 SEM 全模型：N≥200 是底线，N≥300 稳妥。

样本不够时不要硬跑 CFA——拟合指标在小样本下会系统性地失真，报出来的 CFI=0.96 没有意义。

## 一、信度

### 1.1 Cronbach's α（内部一致性）

**逐维度报，不许只报总量表。** 总量表 α 高而某维度 α 低，是常见掩盖方式。

判定阈值（社科惯例）：

| α | 判定 | 处置 |
|---|---|---|
| ≥0.9 | 优秀 | 但要警惕题目冗余，检查是否有近乎重复的题 |
| 0.8–0.9 | 良好 | 可直接用 |
| 0.7–0.8 | 可接受 | 可直接用 |
| 0.6–0.7 | 勉强 | 探索性研究可用，验证性研究需修正并说明 |
| <0.6 | 不可接受 | 必须修正或弃用该维度 |

**α 低不等于题目差，按这个顺序排查：**

1. **反向题漏转**（最常见）→ 查 item-total correlation 有无负值；
2. **坏题**：某题的"删除该项后的 α"明显高于当前 α → 删该题，重算；
3. **维度设定错**：题目跨维度混装 → 先做 EFA 看载荷；
4. **样本同质性过高**：全是一个学校的同一年级 → α 会被压低，属样本问题不是量表问题。

删题要克制：删掉 1–2 题可以，删掉 1/3 以上说明量表本身有问题，须重新论证，
不能靠删题凑 α。

**Python：**

```python
import pandas as pd

def cronbach_alpha(df):
    """df: 每个列是一道题（已反向转换）。返回 (alpha, 删除该题后的alpha列表)"""
    k = df.shape[1]
    item_var = df.var(axis=0, ddof=1).sum()
    total_var = df.sum(axis=1).var(ddof=1)
    alpha = (k / (k - 1)) * (1 - item_var / total_var)
    drop = {}
    for c in df.columns:
        sub = df.drop(columns=c)
        kk = sub.shape[1]
        a = (kk / (kk - 1)) * (1 - sub.var(axis=0, ddof=1).sum() / sub.sum(axis=1).var(ddof=1))
        drop[c] = round(a, 3)
    return round(alpha, 3), drop

# 用法：按维度分组跑
alpha, drop = cronbach_alpha(df[['Q1','Q2','Q3','Q4','Q5']])
print(f"α = {alpha}")
print("删除该题后的 α：", drop)
```

**R：**

```r
library(psych)
psych::alpha(df[, c("Q1","Q2","Q3","Q4","Q5")], check.keys = TRUE)
# check.keys=TRUE 会自动识别并提示反向题，但仍需人工确认后手动反向
```

**SPSS 语法：**

```spss
RELIABILITY
  /VARIABLES=Q1 Q2 Q3 Q4 Q5
  /SCALE('维度一') ALL
  /MODEL=ALPHA
  /STATISTICS=DESCRIPTIVE SCALE CORR
  /SUMMARY=TOTAL.
```

`/SUMMARY=TOTAL` 输出"校正的项总计相关性"和"删除项后的 α"，是排查坏题的关键。
校正项总计相关性应 >0.4；低于 0.3 的题考虑删除。

### 1.2 组合信度 CR（CFA 框架下更严谨，与 α 一起报）

CR 由标准化载荷计算，比 α 更准确（α 假设各题载荷相等，实际很少成立）：

```
CR = (Σλ)² / [(Σλ)² + Σ(1 - λ²)]        λ = 标准化因子载荷
AVE = Σλ² / n                            n = 该维度题数
```

CR ≥0.7、AVE ≥0.5 为达标。**只报 α 不报 CR，在 SEM 类论文里会被要求补。**

### 1.2b McDonald's ω（载荷不等权时的 α 替代）

**α 与 CR 都假设"每道题同等重要"，ω 不假设。** 当题目载荷差异大
（如 0.85 / 0.45 / 0.80 这种），α 会系统性低估信度，ω 才是对的。

```
ω_total = (Σλ)² / [(Σλ)² + Σ(1 - λ²) + 2ΣΣθ_ij]
```

实践中几乎都用三因子简化式（Hayes & Coutts 2020 推荐报告这一种）：

```
ω = (Σλ)² / [(Σλ)² + Σ(1 - λ²)]      ← 与 CR 同式，差别在 λ 来自 CFA 而非 EFA
```

这正是很多人把 ω 与 CR 混为一谈的原因。**要在文中写清用的是哪一条式子**，
否则审稿人会问"你的 ω 和 CR 为什么一样"。

R 实现（`psych::omega` 一次给三种，取 `omega.tot`）：

```r
library(psych)
# 三因子结构，flip 自动处理反向题
om <- omega(df[, items], nfactors = 3, flip = TRUE)
om$omega.tot          # ω_total（含组间相关，最保守）
om$omega_h            # ω_hierarchical（二阶因子模型）
om$alpha              # 同一批载荷算的 α，可直接对比
```

SPSS 无原生 ω，需装 `Omega` 宏（Hayes & Coutts 提供）或用 R 算完粘回。

**什么时候必须报 ω 而不只是 α：**

| 情形 | 要求 |
|---|---|
| 题目载荷差异大（最高/最低 > 1.8 倍） | 必报 ω，α 会低估 |
| 用了多维量表（分量表 + 总分） | 必报 ω_total 与 ω_hierarchical |
| 目标刊是《心理学报》《心理科学》等 | 近五年越来越多要求 ω 与 α 并列 |
| 题目数 < 5 | 必报 ω，α 在小题目数下不稳定 |
| 题目数 ≥ 8 且载荷相近 | α 足够，ω 可放附录 |

**α、CR、ω 三者不要都报。** 报 α + 其中一个（CR 或 ω）即可，
三个一起摆出来只会让人问"你到底信哪个"。选法：题目来自既有成熟量表 → α + CR；
自编/修订量表或载荷差异大 → α + ω。

### 1.3 折半信度（α 之外的交叉验证）

把题目按奇偶或前后分半，算两半总分的相关，再用 Spearman-Brown 校正：

```
r_SB = 2r / (1 + r)
```

r_SB ≥0.7 达标。**必须写明分半方式**（奇偶 / 前后 / 随机），不同分法结果不同，
随机分半要报随机种子。

### 1.4 重测信度（仅两次测量时可用）

同一批人隔 2–4 周重测，算两次总分的 Pearson r，r ≥0.7 达标。
**必须报间隔周数**。间隔太短会虚高（记忆效应），太长会低估（真实变化）。

## 二、效度

效度不是一个数字，是四个分开的论证。**四类分开写，不要混成一句「效度良好」。**

### 2.1 内容效度

两条路，至少要有一条：

**路线 A（自编量表必做）：专家评定**

邀请 5–10 名领域专家对每道题的"代表性"打 4 级分（1=不相关，4=高度相关）。
计算 CVI（内容效度指数）：

- **I-CVI**（单题）：打 3 或 4 分的专家数 / 专家总数。要求 ≥0.78（专家 6 人以上时）。
- **S-CVI/Ave**（全量表）：所有 I-CVI 的平均值。要求 ≥0.90。
- **S-CVI/UA**（普遍一致）：全部专家都打 3 或 4 分的题目比例。要求 ≥0.80。

**路线 B（用成熟量表）：来源论证**

说明量表出自哪篇文献、已被引用多少次、在多少个样本里验证过。
**不许只说「采用成熟量表」而不给出处**——这句话在审稿人眼里等于没说。

### 2.2 结构效度

见 `efa-cfa` 技能，那里有完整流程。这里只强调判定顺序：

```
KMO ≥ 0.7 且 Bartlett p<0.001
        ↓ 才允许做 EFA
EFA：载荷 ≥0.5、无跨载荷、累积解释方差 ≥50%、因子数判定三法一致
        ↓
CFA：χ²/df<3、RMSEA<0.08、CFI/TLI>0.90、SRMR<0.08
```

**KMO <0.7 时不要硬做 EFA**，先看是不是样本量不够或题目太少。

### 2.3 收敛效度

AVE ≥0.5（潜变量能解释其观测指标 50% 以上的变异）。AVE 在 0.4–0.5 之间时，
若 CR >0.6 可勉强接受，但须在文中说明。

### 2.4 区分效度（两种方法，建议都报）

**方法一：Fornell-Larcker 准则**

√AVE > 该构念与其他所有构念的相关系数。做法是给相关矩阵的对角线换成 √AVE，
对角线上的值必须是该行该列的最大值。

**方法二：HTMT（异质-单质比率）**

```
HTMT = 两构念间指标相关的均值 / √(构念1内部指标相关的均值 × 构念2内部指标相关的均值)
```

HTMT <0.85（严格）或 <0.90（宽松）达标。**HTMT 比 Fornell-Larcker 更敏感**，
近年审稿人更认这个，建议两个都报。

## 四、不合格时的处置顺序（按这个顺序，别跳步）

1. **查计分**：反向题转了吗？分值范围对吗？（约 40% 的问题出在这）
2. **查缺失**：是不是整列被填补成均值了？那会把方差压没，α 虚低。
3. **查单题**：item-total correlation <0.3 的题，删掉重算。
4. **查维度**：做 EFA 看题目实际聚成几维，也许你的维度划错了。
5. **查样本**：样本是否过于同质（同校同年级）？同质会压低 α。
6. **最后才考虑改题**：改题需要重新收集数据，代价最大。

**绝对不能做的：** 为了让 α 过 0.7 而反复删题直到达标。这是 p-hacking 的一种，
删了哪些题、删之前 α 是多少，必须如实报告。

## 五、常见审稿人追问与应答

| 追问 | 不合格的应答 | 合格应答 |
|---|---|---|
| 为什么只报 α 不报 CR？ | 沉默 | 补报 CR 与 AVE，说明 α 假设载荷相等 |
| α 和 ω 有什么区别，为什么你的 ω 等于 CR？ | 「两个差不多」 | 说明 ω 用 CFA 标准化载荷代入同一式子，所以数值接近 CR；真正区分的是 ω_total 与 ω_hierarchical |
| 题目载荷差这么多，α 还可靠吗？ | 「α 是惯例」 | 补报 ω，说明 α 在载荷不等权时低估信度（Hayes & Coutts 2020） |
| AVE <0.5 怎么办？ | 删题凑 AVE | 说明 AVE 偏低的原因（题目异质性高），并报 CR>0.7 佐证，或在局限里承认 |
| 区分效度用 Fornell-Larcker 够吗？ | 「惯例如此」 | 补报 HTMT，两个指标互相印证 |
| 样本量够做 CFA 吗？ | 「够」 | 给出 N、题数、参数个数的比例 |
| 反向题怎么处理的？ | 「已处理」 | 写明哪些题反向、转换公式、转换后 item-total 的变化 |
