# 总论与成书

## 一、总论写什么

读档是一篇一篇的，总论要回答**只有并读才出现的问题**。以下是几组被验证过站得住的问题类型，可按实际材料取舍：

1. **概念在各篇里是不是同一个东西。**有的作者把"所有权"当既成范畴直接用，有的在考察这个词怎么来的，有的说这个概念本来就不该用在这个时代。这三种做法之间的张力，是总论最有价值的部分之一。
2. **概念的旅行与翻译。**一个外来概念进入本地材料时经过几次翻译、每次翻译丢掉了什么。
3. **名与实。**官方的名目与实际的支配是不是一回事；国家法上的"无效"是否等于社会中的"失效"。
4. **权利如何被证明。**标识（物上写着谁的名）、凭证（契、券、簿、图册）、惯例（亲邻、族规）、登记，几种方式的历史转移与叠加关系。
5. **材料的层级与各自能证明什么。**哪一层承担举证责任，哪一层只是解释框架；把理论著作当论证前提的，结论可检验性就低。
6. **时间纵深。**讨论的时代越早，所依据的文本越晚；晚出的文本把早期制度描述得更整齐。
7. **研究者的动作。**谁在复原材料、谁在收集语词、谁在作理论演绎、谁在作案例比较；这四类动作的可靠程度不同。
8. **对当下的用处。**历史形态与当代制度争论的对照关系——写成"对照系"，不要写成"渊源"，除非有制度承继的直接证据。

## 二、总论的体例

- 只凭读档写，不回读原文；两篇记录冲突且细节不够时例外，那时必须回原查，不许含糊。
- 判断要标明归属，与读档同一套标记。
- 不出现"（档案 04）"式内部编号引用——读者手上的是一份连贯的文章，不是读档索引。要提某篇时用作者名与篇名。
- 每节要有收束段，回答"这一组并读看出的结论是什么"。
- 长度：13 篇规模的语料，约 2–3 万汉字合适；少于 1.5 万说明还没并起来，多于 4 万多半在复述读档。

## 三、跨篇术语索引（可选附录）

把各篇术语表按主题归组，每条括注出自哪几篇。用途是让读者查"这个词在这批文献里有几种用法"。

- 分组按主题（基本语词／官方标识／地权形态／契约凭证／外国法术语／支配与观念／现代研究用语／跨国对应）；
- 同一术语在不同篇有不同界定时，并列保留差异，不要合并成一句；
- 只收各篇术语表里确实有的，不新增；
- 编号要与读档编号一致——重编号之后附录里的旧编号必须同步改，这一处最容易漏。

## 四、Word 成书的结构

```
封面（标题 + 副题 + 材料范围 + 体例说明）
说明页（五条：材料／体例／判断归属／引文体例／限度）
目录（TOC 域，提示按 F9 更新）
正文（总论 → 各篇读档 → 附录）
页脚（页码域，从正文起编）
```

**说明页那五条必须写**，尤其第五条：

> 限度。这十三篇论文相互之间没有引用关系，本报告所记的"对话"只指各篇与各自学科脉络中既有研究的对话；跨篇的比较与联系，属于本报告在并读之后所作的判断，不是任何一篇论文自身的说法。

不写这一条，读者会把你的并读判断当成学界共识。

## 五、排版细节

| 项 | 设定 |
|---|---|
| 正文 | 宋体小四（12pt），行距 1.5，首行缩进 2 字 |
| 标题 | 黑体，一级 18–20pt、二级 15–16pt、三级 13–14pt |
| 列表项 | 左缩进 0.9cm，字号比正文小一号 |
| 表格 | 转成 Word 真表格（Table Grid），首行加粗，字号 9pt |
| 页边距 | 上下 2.54cm，左右 3.0cm |
| 页码 | 页脚居中，正文另起一节起编 |

表格必须转真表格。直接把 markdown 的竖线行当正文段落塞进去，渲染出来是一堆竖线，读者没法看。

## 六、交付前自查

1. 页数、字数对不对；
2. 目录域能生成（用 LibreOffice 或 Word 渲染一次看）；
3. 封面标题不溢出页面；
4. 表格是真表格且列宽合适；
5. 全文无"第 N 页"式内部注释、无核验过程元话语；
6. 各篇编号连续、无重复、无缺号；
7. 副本同步到用户要的每个位置。
