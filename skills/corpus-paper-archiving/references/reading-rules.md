# 读档判据

## 一、四样验收标准

读完一篇稿子，先用这四样自检。四样里任何一样写不出来，就不是"文章没写清楚"，是"我没读完"。

### 1. 问题关注

不是问"他研究了什么题目"，而是问"他为什么要写这一篇"。可操作的写法：把这篇文章换成一段话——"他不同意某种说法，认为那说法错在 X，他要用 Y 证明 Z"。如果这段话里你只能填"他研究了汉代的所有权"，说明你还没读到问题，只读到了题目。

判断标准：问题关注要能说清"他在跟哪个既有说法较劲"。如果作者确实没有对话对象（纯材料描述），如实写"本文以描述制度为主，未设定明确的论辩对象"——这是结论，不是偷懒。

### 2. 理论预设

他默认了什么、没论证就用了什么。三类最常见：

- **概念预设**：直接拿一个现代概念往古代材料上套（"所有权""人本主义""封建"），不交代这个概念能不能用。
- **方法预设**：相信某种材料的可靠性而未加论证（拿《周礼》《管子》当制度实录）。
- **前提预设**：某个未经证明的判断被当作推理起点（"占有即财产""法律禁止即法律有效"）。

**这一项写不出来，几乎一定是没读懂他的论证。** 因为预设就藏在"他从哪里出发"这一步上；读懂了推理起点，预设自然现形。

例外宽容：有些文章的理论预设和论证逻辑确实薄弱甚至混乱。**遇到这种情况不要死磕**，但护栏是——问题关注与核心观点这两样不能豁免（写不出来就是没读懂，不是文章不行）；理论预设与论证逻辑可以如实写"薄弱""不明"，但**必须指出断裂点**：

- 能指出断点（"第三节从史料跳到了主张，中间缺一步"）＝文章的问题；
- 指不出、只能说"很复杂"＝我没读透，必须重读。

遇到薄弱时按这四行记：各节实际在做什么；哪些是本人主张、哪些只是转述或口号复述；有无论证结构；有无对话对象。最后另起一段写"我的判断"，必须标明是判断而非作者主张，且必须基于可核的观察，不许基于感觉。

### 3. 行文与论证逻辑

能复原出"由 A 推知 B、由 B 推知 C、因为 A 所以 B"。复原不出，可能是逻辑混乱，也可能是我没读懂——先假定后者。

**先认出这一段用的是哪种推理，再用该形式自己的尺子量它。** 逻辑形式远不止演绎一种，判错了尺子会把好文章判成混乱：

| 形式 | 该问的问题 |
|---|---|
| 演绎 | 前提真不真？形式有效吗？ |
| 归纳 | 样本够不够？有没有反例？ |
| 类比 | 两边的同异是否在关键处？ |
| 因果 | 有没有第三因？时间顺序对吗？ |
| 反证／归谬 | 被否定的那个对立面是不是唯一选项？ |
| 选言排除 | 选项列全了吗？ |
| 二难 | 两个角都真的尖吗？ |
| 区分界定 | 区分的标准能不能一贯执行？ |
| 必要／充分条件 | 有没有把充分说成必要？ |
| 例证反驳 | 例子是否典型？能否支撑全称命题？ |
| 诉诸权威 | 权威在该问题上有资格吗？ |

**诉诸权威不是逻辑支撑，必须单独标出来**，不能混进"论证链"里当作一环。

法律史、制度史论文的规范主张多为"实然到应然"的跨越（史料显示如此，所以立法应当如此），**不能一律用演绎的尺子判其混乱**。要先确认他在用哪种推理，再判。

### 4. 核心观点

他自己主张什么。分条写，每条带材料依据。注意与第三节分开：**别人说过的话不算他的核心观点**，哪怕他大段复述。

## 二、锚句取证的操作

- 每条论断挂一句逐字原文；
- 分两遍做：第一遍理解，第二遍只抄锚句（边理解边抄会把记忆写进引文）；
- 抄完回底本核，**不许凭记忆**；
- 引文片段截得稍长（15 字以上）以保证唯一命中；
- 页码按用户要求处理：用户不要页码就不印，靠"章节名 + 原文语句"定位。

## 三、归属标记

| 标记 | 用于 |
|---|---|
| 〔作者主张〕 | 论文作者自己的判断 |
| 〔转述某某〕 | 作者引述并转述的他人观点 |
| 〔史料记载〕 | 律文、简牍、判例、契约、档案、方志等原始材料 |
| 我的判断 | 读档撰写者的分析、推测、批评 |

第三条最容易漏：作者引一段律文，你顺手写进"核心主张"，就把史料变成了主张。

## 四、验漏的双重机制

- **摘要**验"核心观点漏没漏"（作者自己的论点清单）；
- **结构巡检**验"正文覆盖全不全"（章节名、每节收束句）。

摘要不写理论预设与论证逻辑，所以还要专门抓**作者交代立场或转折的句子**：方法论声明、从史料跳到主张的那一句、各节的收束句。

## 五、允许回填与重读

后面出现的新概念，回头在已完成的读档里补格子；补不上就写"未涉及"或回查原文。不要为了叙事整齐而制造前后呼应。
