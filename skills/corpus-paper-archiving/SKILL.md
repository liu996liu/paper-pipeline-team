# 逐篇读档：从一批论文到一份可核对的总结

用户在做的往往是"替我把这些论文读了"，而不是"写一篇综述文章"。两者的差别在质检：综述可以只挑要害，读档必须每篇都过一遍，并且让读者在**不打开原文**的情况下判断你的记录可不可信。

## 三条不能绕的规矩

**一、不预筛。**"哪篇重要"这个判断本身就是跳过的一种伪装。十三篇也好三十篇也好，逐篇通读。允许的例外只有一种：用户明确指定读哪几篇。

**二、单篇隔离。**一次只在上下文里装一篇完整文字，从头读到尾，不删减。读完立刻写成读档落盘，再换下一篇；写第二篇时不加载第一篇的笔记。跨篇印象是最后一步的事，不是读的时候的事。

**三、判断与转述分家。**凡属作者的主张标〔作者主张〕，转述他人标〔转述某某〕，出自律文／简牍／判例／契约／史料的标〔史料记载〕，自己的分析推测一律写"我的判断"。这三样混在一句话里，读档就废了。

为什么是这三条：读档的用途是"替代原文被阅读"。凡是读档说错的地方，读者没有第二道防线。

## 工作流程

### 1. 清点底本，先做完整性对账

拿到 PDF 与文本两套材料时，**先确认文本没丢内容再读**：逐篇比汉字数（差 0.5% 以内可用），并抽一段已知内容逐字对账。PDF 转出的文本常有三种损伤，遇到要记下来并调整取证方式：

- **丢标点**（只留汉字序列）：引文只能保证汉字序列，标点按文义补入。
- **按页插入反引号与断行**：跨行句子被切断，用文本写的引文必然在跨行处断裂。
- **双栏扫描件左右栏逐字交错**：同一视觉行内两栏文字穿在一起，脚注、页眉、作者简介也会插进正文。这类底本的逐字核验会大量假阴性。

有 PDF 原件时，用 `scripts/pdf_text.py` 另抽一份干净底本作第二底本，两份交叉核验：

```bash
python scripts/pdf_text.py <PDF目录> --out-dir <工作目录>/_pdftxt
```

若需要"某条引文在原书第几页"（用户或许不要页码，但内部核对、后来者回查都可能用得上），用 `scripts/align_pages.py` 把文本底本与 PDF 逐页对齐，产物是页号到正文位置的映射；对齐是否可靠，看各篇"尾残差"是否为 0。

```bash
python scripts/align_pages.py --pdf <PDF目录> --md <文本目录> --out <输出目录>
python scripts/align_pages.py --pdf <PDF目录> --md <文本目录> --locate 篇名关键词 15
```

### 2. 逐篇通读，按四样判据验收

读完一篇，先用四样东西自检，写不出来就是没读完，回去重读，不要在档案里糊过去：

1. **问题关注**——他在回答什么问题；
2. **理论预设**——他默认了什么、没论证就用了什么；
3. **行文与论证逻辑**——由 A 推 B、由 B 推 C 能否复原；
4. **核心观点**——他自己主张什么。

判据的细则、逻辑形式清单、"理论预设薄弱"的豁免条件与断点写法，见 [读档判据](references/reading-rules.md)。

### 3. 取证：锚句 + 逐字核验

每条论断挂一句逐字原文。操作上分两遍：第一遍理解，第二遍只抄锚句。抄完**必须回底本核**，不能凭记忆写——凭记忆写出来的引文是"重构＋拼源"的混合体，看起来完全像原文。

用 `scripts/quote_check.py` 批量核验：

```bash
python scripts/quote_check.py check  <读档.md> --src <底本.md> [--src2 <第二底本.txt>]
python scripts/quote_check.py scan   <目录> --src <底本目录>        # 全档一次跑完
```

输出四类，只对第三类动手：

| 判定 | 含义 | 处理 |
|---|---|---|
| 精确 | 整句在底本中 | 通过 |
| 容噪（≥0.8） | 双栏交错、跨行被切断 | 保留，可在读档里加一句说明 |
| 需查（<0.8） | 拼接或伪造 | **逐条处理**，见下 |
| 过短（<12 汉字） | 词组引号、术语引号 | 不核，直接放过 |

一次真实的全档结果可作参照：13 篇读档、约 290 条引文，精确 287、容噪 12（均为双栏断裂）、需查 0；而开跑时需查有 4 条，全部是真问题。也就是说这条检查不是形式——它每次都能抓到东西。

判定方法与阈值见 [引文核验](references/quote-verification.md)。核心只有三条：归一为纯汉字流后整句比对；不中再用 8 字滑窗看是否只是跨栏／跨行断裂；仍不中的就是伪造或改写，删掉或降为间接转述。

**引文造假的三种真实形态**（都在实做中抓到过，形态稳定，按此排查最省力）：

1. **二手介绍冒充原文**：把别人对该文的概述抄成引文。特征是措辞比作者更书面、更概括，且关键词在底本里查不到。
2. **术语重构**：把学界通用的说法（如"赤裸的所有权"）写进引号，当成这篇作者的话。特征是整句查不到，但每个词都能在底本别处找到。
3. **两句拼一句**：前半句在底本第 3 页、后半句在第 5 页，中间用逗号接上。特征是 8 字滑窗命中率停在 0.6–0.8，且失败窗口集中在一处断裂点。

**发现引文是拼接时怎么办**：截到断裂点前的可核部分，末尾加省略号，后面接括号说明"作者就此续论：……"，而不是整条删掉。这样既保住信息，又不再冒充原文。

改完任何一条引文，都要记得**重建 Word**——交付物不会自己更新。

### 4. 写读档（两层结构）

每篇读档分两层，缺一层都不完整：

- **第一层「提要：这篇论文说了什么」**——2,000–2,800 汉字，连续散文，六段：这篇在处理什么问题／核心主张／本文自身的结构与方法／跟谁对话／依据／论证链与松动处／我读出的问题与它的位置。供快速阅读，读者不跳转就能知道这篇讲了什么。
- **第二层「档案记录」**——八节编号格子：定位、核心主张、跟谁对话、依据、论证链与松动处、我读出的问题、原文直引、术语表。供核验与跨篇比较。

两层内容必须重叠（不重叠说明有一边没尽职），但**功能不同**：提要写给"这篇说了什么"，八节写给"这条主张是谁说的、凭什么、原文在哪、我信不信"。模板、每格写什么、常见写坏的样子见 [读档模板](references/archive-template.md)。

### 5. 写总论

读档齐了再写总论。总论**只凭读档**，不回读原文（例外：两篇记录冲突且细节不够时必须回原查，不许含糊）。总论要回答的是跨篇才出现的问题：概念在各篇里是不是同一个东西、材料的可靠性层级、名与实的分离、权利靠什么被证明、研究者的方法差异。体例见 [总论与成书](references/output-shape.md)。

### 6. 汇总成 Word

读档与总论齐备后合成一份文档：封面 → 说明（材料、体例、判断归属、引文体例、限度）→ 目录 → 总论 → 各篇读档 → 跨篇术语索引（可选附录）。

```bash
python scripts/docx_build.py --archives <读档目录> --overview <总论.md> --out <输出.docx> [--appendix <附录.md>] [--copy-to <目录>]
```

要求：正文宋体小四、行距 1.5、首行缩进二字；标题黑体分级；表格转成 Word 真表格；目录用 TOC 域（提示用户按 F9 更新）；页脚插页码域。**成稿不印页码**（用户若不要页码就不要），引文靠"章节名 + 原文语句"定位。

## 规模与分工

一篇 5,000–18,000 汉字的论文，读档正文约 9,000–13,000 汉字。超过八篇时上下文会撑不住，用子代理并行，但**必须给死模板**，见 [并行与分工](references/delegation.md)。亲读与委派的质量差通常出现在三处：理论预设写不出、松动处写成复述、引文凭记忆写。委派回来先查这三处。

## 交付前的五条底线

1. **不写页码**（用户不要时），也不写任何关于自己任务、转换过程、核验过程的元话语进正文——"以上引文均经核对"这类句子属于工作日志，不属于读档。
2. **记录里不出现"第 N 页"式内部注释**。核验记录另存一个文件，不进交付物。
3. **同名同篇只留一份读档**。重编号前先核对，避免同一篇有两份、另一篇一份都没有。
4. **限度要写明白**：这批论文之间有没有真实引用关系、哪些判断属于你的并读所得、哪些地方你没能确证。写在说明页，不写在正文里。
5. **不往用户的材料目录里写东西**。脚本的输出（抽文、索引、临时文件）一律落在工作目录；用户的论文目录只读。

## 收工前跑一遍

```bash
python scripts/quote_check.py scan <读档目录> --src <底本目录>     # 需查必须为 0
```

再确认四件事：每篇读档都有提要一层与八节一层；提要在 2,000–2,800 汉字；交付物是最后一次改动之后重新生成的；副本与工作副本一致（用文件大小与修改时间核对）。

## 怎么触发

用户说"把这些论文读完，写个总结"、"帮我读这些文献省时间"、"整理这个文件夹里的论文出报告"、"不要只看摘要，每篇都要读"，即适用。先问三件事再动手：**要不要页码、每篇写多长、要不要一篇统起来的总论**。这三项决定成品形态，事后返工代价很大。
